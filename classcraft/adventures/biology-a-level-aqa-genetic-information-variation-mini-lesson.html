Mission 1

Where cells keep their DNA

  • Prokaryotes have no nucleus: their DNA lies in the cytoplasm.
  • Prokaryotic DNA: short, circular, not associated with proteins.
  • Eukaryotes keep most of their DNA in the nucleus, as several linear chromosomes.
  • Each chromosome holds one very long DNA molecule, associated with histone proteins.
  • A chromosome = a DNA molecule + its associated proteins.
  • Mitochondria and chloroplasts have DNA too: short, circular, not associated with protein, like prokaryotic DNA.
Quick check
?A leaf cell contains DNA in its nucleus, its mitochondria and its chloroplasts. Which statement about this DNA is correct?
Mission 1

Packing it in

  • Stretched out, the DNA in one human body cell is about 2 m long. The nucleus is about 6 µm across.
  • (1) DNA winds around histones.
  • (2) The wound DNA coils, and coils again.
  • (3) Before nuclear division, each chromosome condenses: short, thick, visible, and movable without tangling.
  • Between divisions, chromosomes are less condensed, so DNA can be copied and its genes used.
  • Packing changes how tightly DNA is folded. It never changes the base sequence.
  • Say: "DNA is wound around histones" — not: "histones wrap around the DNA".
Quick check
?A line of eukaryotic cells grown in a laboratory carries a mutation that greatly reduces the amount of histone protein the cells make. Which prediction about the DNA in the nuclei of these cells is best supported?
Mission check

?Each chromatid of human chromosome 1 contains one DNA molecule about 85 mm long. When the cell divides, the condensed chromosome is about 10 µm long (illustrative round value). Which statement is correct?

One molecule, thousands of times longer than the chromosome it forms. Histones, then coil upon coil, make it fit.

Mission 2

What is a gene?

  • A gene is a sequence of bases on DNA that codes for the amino acid sequence of a polypeptide.
  • A gene may instead code for a functional RNA, such as rRNA or tRNA.
  • Each gene sits at a fixed position on a chromosome: its locus.
  • Say: "a gene codes for a polypeptide" — not: "a gene codes for a characteristic".
Mission 2

Why groups of three?

  • DNA has 4 bases. Polypeptides use 20 amino acids.
  • One base per amino acid: 4 codes. Two bases: 4² = 16. Too few.
  • Three bases: 4³ = 64 codes. Enough for all 20.
  • So a sequence of three bases, a base triplet, codes for one amino acid. This is the genetic code.
  • On mRNA, each triplet is a codon. The sequence is read in codons.
  • 61 codons code for amino acids; 3 are stop codons.
Quick check
?Why does the genetic code use codons of three bases rather than two?
Mission 2

Features of the code

  • Non-overlapping: each base belongs to one triplet only. Triplets are read one after another.
  • Degenerate: most amino acids have more than one codon. Glycine: GGU, GGC, GGA, GGG.
  • Universal: the same codon codes for the same amino acid in almost all organisms.
  • AUG is the start codon. It also codes for methionine.
  • Stop codons (UAA, UAG, UGA) code for no amino acid.
  • Say: "degenerate: several codons, one amino acid" — not: "one codon, several amino acids".
Quick check
?The genetic code is described as degenerate. What does this mean?
Mission 2

Worked example: reading the code

mRNA: AUGGCUUGGAAAUAGCC

  • Find the start codon: AUG.
  • Split into triplets from there: AUG | GCU | UGG | AAA | UAG | CC
  • Look up each codon in the table: Met – Ala – Trp – Lys – stop.
  • Stop at the stop codon. The polypeptide has 4 amino acids.
  • Exams give you the codon data you need. You do not learn codons by heart.
Quick check

Mission 2

One code for (almost) all life

  • Bacteria given the coding sequence for human insulin (no introns) make the same polypeptide chains as human cells. They read the codons the same way.
  • A few small variants exist (e.g. in mitochondria), so the code is nearly universal.
Quick check
?The gene for human insulin has been inserted into bacteria, which then translate it into a polypeptide with the same amino acid sequence as the polypeptide made in human cells. Which feature of the genetic code makes this possible?
Mission 2

Coding and non-coding DNA

  • In eukaryotes, much of the DNA does not code for polypeptides. In humans, only about 1–2% does.
  • Exons: sequences within a gene that code for amino acids.
  • Introns: non-coding sequences between exons. They are removed after transcription.
  • Between genes: non-coding multiple repeats, short base sequences repeated many times.
  • Say: "introns are non-coding" — not: "introns are useless".
Mission 2

Genome and proteome

  • Genome: the complete set of genes in a cell.
  • Proteome: the full range of proteins that a cell is able to produce.
  • The proteome can be larger than the number of genes.

Mission 3

Mission 3: Your DNA never leaves the nucleus. So how do its instructions reach the place where proteins are made?

Make a guess: Your DNA never leaves the nucleus. So how do its instructions reach the place where proteins are made?

Mission 3

Transcription comes first

  • Transcription: making an RNA copy of a gene, using one DNA strand as a template.
  • It is the first stage of gene expression. Translation comes next.
  • In eukaryotes, the mRNA leaves the nucleus through a nuclear pore. The DNA stays behind.
Mission 3

Transcription, step by step

  • RNA polymerase binds at the start of a gene. The DNA unwinds; hydrogen bonds between bases break.
  • Only one strand, the template strand, is read.
  • Free RNA nucleotides pair with exposed template bases: A–U, T–A, C–G, G–C. Hydrogen bonds hold each pair.
  • RNA polymerase joins adjacent RNA nucleotides with phosphodiester bonds, building the sugar–phosphate backbone.
  • The RNA separates from the template. The DNA rewinds.
  • Say: "RNA polymerase joins adjacent RNA nucleotides" — not: "RNA polymerase pairs the bases". Base pairs form by hydrogen bonding.
Quick check
?A section of the DNA template strand of a gene has the base sequence TACGCAT. What is the base sequence of the RNA transcribed from this section?
Mission 3

Worked example: three sequences

  • Template strand: T A C G G A T C
  • mRNA (complementary to the template): A U G C C U A G
  • Coding strand (paired with the template): A T G C C T A G
  • So mRNA = the coding strand, with U in place of T.
  • mRNA is a single strand. Its sugar is ribose. It is a copy of one gene, so it is short.
  • Its bases are read in triplets: codons.
Quick check
?During transcription, what holds each RNA nucleotide in position against the DNA template strand while it is being added to the growing RNA?
Mission 3

Prokaryotes and eukaryotes

  • Prokaryotes: transcription produces mRNA directly.
  • Eukaryotes: transcription produces pre-mRNA. It is spliced to make mRNA (see Mission 4).

Mission check

?α-Amanitin, a toxin from the death cap mushroom, blocks the RNA polymerase that makes mRNA in eukaryotic cells. It has no effect on DNA polymerase or on ribosomes. Which prediction about liver cells exposed to it is correct?

The DNA stays put. RNA polymerase makes a temporary, complementary copy of one gene, and that copy carries the message out. Stop RNA polymerase and the message stops.

Mission 4

From pre-mRNA to mature mRNA

  • In eukaryotes, the whole gene, introns included, is transcribed. The product is pre-mRNA.
  • Splicing: the introns are removed and the exons are joined.
  • The mature mRNA leaves the nucleus.
  • Say: "introns are removed from the RNA" — not: "introns are cut out of the gene's DNA".
Quick check
?A eukaryotic gene is transcribed into a pre-mRNA with five sections, in order: exon 1, intron 1, exon 2, intron 2, exon 3. Which is the mature mRNA?

Mission 5

What is a gene mutation?

  • A gene mutation is a change in the base sequence of DNA.
  • Many arise as errors during DNA replication that are not corrected.
  • The changed DNA is transcribed into changed mRNA. That may change the polypeptide.
  • Larger changes, to whole chromosomes, are chromosome mutations.
Mission 5

Three ways to change a sequence

  • (1) Substitution: one base replaced by another. Same length.
  • (2) Deletion: a base removed. One shorter.
  • (3) Insertion: a base added. One longer.
  • AQA calls insertion addition.
  • Compare the sequences base by base, and count their lengths.
Quick check
?Part of the base sequence of a gene is GAT TCA GGC ATT before a mutation and GAT TCG GCA TT after it. Which type of gene mutation has occurred?
Mission 5

A substitution: three possible outcomes

  • A substitution changes one codon only. The reading frame is untouched.
  • Outcome 1: the new codon codes for the same amino acid. No change. The code is degenerate.
  • Outcome 2: the new codon codes for a different amino acid. One amino acid changes.
  • Outcome 3: the new codon is a stop codon. The polypeptide is cut short.
  • You may also see: silent (1), missense (2), nonsense (3).
Mission 5

Worked example: four mutations, one gene

  • Code table: AUG Met · GCA, GCU Ala · UGG Trp · AAG Lys · GAG Glu · CUU Leu · CAU His · GGA Gly · AGC Ser · UGA stop.
  • Normal mRNA: AUG GCA UGG AAG CUU → Met–Ala–Trp–Lys–Leu.
  • (a) GCA → GCU: Met–Ala–Trp–Lys–Leu. No change.
  • (b) AAG → GAG: Met–Ala–Trp–Glu–Leu. One amino acid changed.
  • (c) UGG → UGA: Met–Ala–stop. Two amino acids only.
  • (d) Delete the G of codon 2: AUG CAU GGA AGC UU… → Met–His–Gly–Ser… Every codon after the deletion changes.
Quick check
?In mRNA the codons GCU, GCC, GCA and GCG all code for alanine. A base substitution in a gene changes the codon GCU in its mRNA to GCC. What is the effect on the polypeptide?
Mission 5

Deletions and insertions: the frame shifts

  • The ribosome reads in threes from the start codon. There are no gaps or commas.
  • Delete one base and every later base moves up one place: a frameshift.
  • Inserting one base does the same.
  • Every downstream codon is regrouped. Codons before the mutation are unchanged.
  • A new stop codon usually appears early. The polypeptide almost always stops working.
  • Three bases added or removed: the frame is kept. One amino acid is gained or lost (a neighbour may change too).
  • Say: "frameshift: all downstream triplets change" — not: "one base, one amino acid".
Quick check
?In a hypothetical bacterium, strain A has a deletion of one nucleotide in codon 10 of a gene that has 300 codons. Strain B has a deletion of the three adjacent nucleotides that make up codon 10 of the same gene. Which prediction about the polypeptides translated from the two genes is best supported?
Mission 5

Three more changes to bases

  • Inversion: a group of bases is reversed. …TAC GGA… → …TAC AGG… Several codons may change.
  • Duplication: a group of bases is repeated. Frameshift unless the repeat is a multiple of three.
  • Translocation of bases: a group of bases moves to another place. Both sites change.
  • These are still gene mutations: changes in bases, not whole chromosomes.
  • To predict the effect, ask: how many triplets change? Is the frame shifted?
Mission 5

A real point mutation: sickle cell

  • Gene: β-globin, one of the polypeptides of haemoglobin.
  • DNA coding strand: GAG → GTG. mRNA: GAG → GUG.
  • Amino acid 6: glutamic acid (charged) → valine (non-polar).
  • At low oxygen, these haemoglobin molecules stick together into long fibres.
  • Red blood cells become sickle-shaped, rigid, and block capillaries.
  • One base out of hundreds. Two copies of this allele: sickle cell anaemia.
Quick check
?In the allele that causes sickle cell anaemia, the mRNA codon for amino acid 6 of the beta chain of haemoglobin is GUG instead of GAG. GAG codes for glutamic acid and GUG codes for valine. What is the effect of this mutation on the protein?
Mission 5

Harmful, neutral or beneficial?

  • Harmful: the protein no longer works, or works worse.
  • Neutral: no detectable effect on the organism. Silent mutations are usually neutral.
  • Beneficial: the new protein gives an advantage.
  • The environment decides: a mutation that lets a bacterium survive an antibiotic helps only where that antibiotic is present.
  • Say: "silent: same amino acid sequence" — not: "silent: no effect on the phenotype". That is neutral.
Mission check

?A gene codes for a polypeptide of 400 amino acids. A single base substitution changes the fifth codon of its mRNA from UAC to UAA. In the code table, UAC codes for tyrosine and UAA is a stop codon. What is the most likely effect?

One letter can do nothing, change one amino acid, or stop the whole chain. It depends on which codon it creates.

Mission 6

Copying is almost perfect

  • Every cell division copies billions of bases.
  • DNA polymerase sometimes pairs the wrong base. Proofreading and repair fix almost all errors.
  • The few that escape become permanent: spontaneous mutations.
  • Errors in DNA repair add more.
  • So mutations happen even with no harmful agent present. Each person carries dozens of new mutations neither parent had.
Mission 6

Mutagens raise the rate

  • A mutagen increases the rate of mutation.
  • Chemical mutagens: e.g. nitrous acid (alters bases so they mispair); benzo[a]pyrene in tobacco smoke (binds to bases).
  • Ultraviolet light: joins neighbouring thymines, distorting the DNA.
  • Ionising radiation (X-rays, gamma rays): breaks DNA strands and damages bases.
  • Not mutagens: visible light, microwaves, radio waves. Too little energy to change DNA.
Quick check
?Cultures of cells were exposed separately to (i) ultraviolet light, (ii) visible light and (iii) nitrous acid, a chemical that alters bases in DNA. Which treatments are expected to raise the mutation rate above the background rate?
Mission 6

Random, not directed

  • A mutation can happen anywhere in the genome.
  • No natural mechanism makes a chosen change to a chosen base to produce a useful trait.
  • A mutagen raises the rate. It does not pick the gene.
  • The environment selects among variants that already exist. It does not create them.
  • Say: "a random mutation that happened to give resistance" — not: "the bacteria mutated to become resistant".
Mission 6

Mission check

?When a new insecticide was first used on a crop, it killed nearly all individuals of a hypothetical pest insect. After several years of use, most of the pest population was resistant. Which statement best explains how resistance became common?

Mutation supplies variation by chance; the environment only chooses among what is already there.

Recap

The big ideas

Mission 1

  • Prokaryotic, mitochondrial and chloroplast DNA: short, circular, not associated with protein. Nuclear DNA: very long, linear, with histones, forming chromosomes.

Mission 2

  • A gene is a base sequence coding for a polypeptide's amino acid sequence; it has a fixed locus.
  • The code is a triplet code, read in codons: degenerate and (nearly) universal.
  • It is also non-overlapping: each base is read in one triplet only.

Mission 3

  • RNA polymerase reads one DNA strand (the template) and joins complementary RNA nucleotides (A–U, C–G) to make mRNA.
  • mRNA has the coding strand's sequence with U for T; the DNA template is unchanged.
  • Prokaryotes make mRNA directly; eukaryotes make pre-mRNA, then splice it.

Mission 4

  • Eukaryotic pre-mRNA is spliced: introns removed, exons joined.

Mission 5

  • Substitutions change one codon: same amino acid (degenerate code), one different amino acid, or an early stop. Deletions and insertions not in multiples of three shift the frame and change every downstream codon.
  • Inversion, duplication and translocation of bases are gene mutations too: count the triplets changed and check the frame.

Mission 6

  • Mutations arise spontaneously from copying and repair errors, at random: the environment selects among them but does not direct them.
  • Mutagens such as UV, ionising radiation and some chemicals raise the rate but never aim it.
