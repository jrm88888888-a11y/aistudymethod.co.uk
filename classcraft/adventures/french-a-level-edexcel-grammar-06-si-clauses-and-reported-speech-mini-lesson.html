Si-clauses & reported speech

Two high-value A-Level structures. Si-clauses ("if…") follow three fixed tense patterns, and the same one golden rule governs all three. Reported speech turns direct quotation into indirect speech with a predictable backshift of tenses.

si-clause = fixed tense pairingsreported speech = backshift + que + time shifts

Si-clauses · Type 1

Type 1 — the real condition

When the condition is real / likely, use si + présent in the "if" clause and the présent, futur or impératif in the main clause:

Si + présent → présent / futur / impératifSi j'ai le temps, je viendrai.
  • Si j'ai le temps, je viendrai. — If I have time, I'll come.
  • Si tu étudies, tu réussiras. — If you study, you'll pass.
Si-clauses · Type 2

Type 2 — the hypothetical

For a hypothetical / unlikely present situation, use si + imparfait with the conditionnel présent in the main clause:

Si + imparfait → conditionnel présentSi j'avais le temps, je viendrais.
  • Si j'avais le temps, je viendrais. — If I had time, I would come.
  • Si j'étais riche, je voyagerais. — If I were rich, I would travel.

Si-clauses · Type 3

Type 3 — the impossible past

For an impossible / regretted past situation, use si + plus-que-parfait with the conditionnel passé in the main clause:

Si + plus-que-parfait → conditionnel passéSi j'avais eu le temps, je serais venu.
  • Si j'avais eu le temps, je serais venu. — If I had had time, I would have come.
  • Si j'avais su, je serais venu. — If I had known, I would have come.
The golden rule

Never in the si-clause

Whatever the type, one rule holds every time:

✗ never the futur or the conditionnel… inside the 'si' clause itself
  • ✓ Si je suis libre… — not si je serai libre
  • ✓ Si j'étais riche… — not si je serais riche

Marker magnet: *si je serais is one of the most-penalised errors at A-Level. The conditional lives in the main clause, never after si.

Reported speech

Direct → indirect: the backshift

When you report what someone said after a past reporting verb (il a dit que…), the tenses shift back one step and you add que:

direct speechreported (after past verb)
présentimparfait
passé composéplus-que-parfait
futurconditionnel
  • "Je suis fatigué" → Il a dit qu'il était fatigué.

Reported speech

Time & place words shift too

Alongside the tenses, the time and place markers move into the reported frame:

directreported
aujourd'huice jour-là
demainle lendemain
icilà

Example: "Je pars demain" → Il a dit qu'il partait le lendemain.

Recap

Your si-clause & reported-speech toolkit

Type 1 (real): Si + présent → présent / futur / impératif.

Type 2 (hypothetical): Si + imparfait → conditionnel présent.

Type 3 (impossible past): Si + plus-que-parfait → conditionnel passé.

Golden rule: never the futur or the conditionnel inside the si-clause.

Reported speech: présent→imparfait, passé composé→plus-que-parfait, futur→conditionnel; add que; shift time words (demain→le lendemain).
