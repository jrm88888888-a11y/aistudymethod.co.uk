Cyber security & ethics

This mini-lesson walks you through Cyber Security & Ethics: the threats to a computer system (cybercrime and malware), how we protect networks and data, the key laws that make computer misuse illegal, and the ethical & moral issues around personal data.

Work through each screen, answer the questions as you go (some are wordy, some are recall) and collect ⭐ stars. Press Start when you're ready.

Threats · cybercrime

Cybercrime & threats to security

Cybercrime is any crime committed using a computer or network. The spec lists several key threats:

  • Hacking — gaining unauthorised access to a computer system.
  • Data theft — stealing personal or confidential data.
  • Denial of service (DoS) — flooding a system with traffic so it can't respond to genuine users.
  • Phishing — fake emails/messages that trick users into revealing passwords or bank details.
  • Spamming — sending unwanted bulk emails.
  • Digital forgery — creating fake digital documents or images.

Watch out: phishing tricks the user into handing over details; hacking forces access directly; a DoS attack doesn't steal data — it just knocks a service offline by overloading it.

Threats · malware

Malware — the main forms

Malware (malicious software) is written to damage or take control of a system. Know these five forms:

  • Virus — attaches itself to a file; spreads only when that infected file is run.
  • Trojan horse — disguised as legitimate software the user installs willingly.
  • Worm — self-replicating; spreads across networks on its own, with no host file.
  • Key logger — secretly records keystrokes to steal passwords and PINs.
  • Spyware — secretly gathers information about the user and reports it back.

Protection · networks & data

Protecting networks & data

Networks and data can be protected in several ways:

  • Encryption — scrambles data so only authorised parties with the key can read it.
  • Passwords / authentication — check who a user is (also biometrics, 2FA).
  • Levels of access (access rights) — users only get the access they need.
  • Backup — a spare copy of data, so it can be restored after loss or attack.
  • Firewall — controls incoming/outgoing network traffic and blocks unauthorised access.

Key point: encryption doesn't stop data being stolen — it makes stolen data unreadable without the key. A firewall is what blocks unauthorised traffic getting in.

Law · legislation

Key computer legislation

The spec covers three key laws — learn the years:

  • Data Protection Act 1998 — protects personal data; has eight principles; gives rights to the data subject; sets duties for the data controller and the Information Commissioner.
  • Computer Misuse Act 1990 — makes unauthorised access (hacking), unauthorised access with intent, and unauthorised modification of data illegal. Covers hackers, viruses and spyware.
  • Copyright, Designs and Patents Act 1988 — protects creators' work; breaches include software piracy and licensing infringements.

Ethics · moral considerations

Ethical & moral considerations

Beyond the law, computing raises ethical and moral issues that you should be able to discuss:

  • Internet misuse and social media misuse — cyberbullying, spreading false information.
  • Access to personal information — who can see your data, and should they?
  • GPS & tracking — location data can be helpful but also invade privacy.
  • Security of personal data — concerns over how organisations store and share it.
  • Environmental issues — e-waste from discarded devices and the energy use of data centres.

Exam tip: ethical questions rarely have a single "right" answer — CCEA wants you to discuss the benefits and drawbacks and reach a balanced conclusion, not just list points.

Recap

The big ideas to know

Threats: hacking (unauthorised access) · phishing (tricks the user) · DoS (floods a system) · data theft · spamming · digital forgery

Laws: Computer Misuse Act 1990 (hacking) · Data Protection Act 1998 (personal data, 8 principles) · Copyright, Designs & Patents Act 1988 (piracy)
