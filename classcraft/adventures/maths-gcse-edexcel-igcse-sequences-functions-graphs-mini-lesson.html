Algebra · sequences

Two kinds of rule

  • A term-to-term rule gets each term from the one before: 5, 9, 13, 17, … is "add 4".
  • A position-to-term rule (the nth term) gets any term from its position nn: here 4n+14n + 1.
  • Substitute nn to find a term: the 10th term is 4×10+1=414 × 10 + 1 = 41.
  • The chessboard has term-to-term rule "double".
Worked example Algebra · sequences

Finding the nth term of a linear sequence

Question

    Find the common difference: 10−7=310 − 7 = 3, so the nth term starts 3n3n
  2. 2
    Compare with 3n3n (3, 6, 9, 12): each term is 4 more, so add 4
  3. 3
    Write the rule: nth term =3n+4= 3n + 4
  4. 4
    Substitute n=100n = 100: 3×100+4=3043 × 100 + 4 = 304
  5. 5
    Solve 3n+4=1003n + 4 = 100: n=32n = 32, a whole number, so 100 is the 32nd term
Answer
nth term 3n+43n + 4; 100th term 304; 100 is a term (the 32nd).

Algebra · sequences

Special sequences

  • Square numbers n2n²: 1, 4, 9, 16, … and cube numbers n3n³: 1, 8, 27, 64, ….
  • Triangular numbers: 1, 3, 6, 10, 15, … (add 2, then 3, then 4, …).
  • A geometric sequence multiplies by the same number rr each time: 3, 6, 12, 24 (r=2r = 2). The chessboard 1, 2, 4, 8, … is geometric: square nn holds 2n−12ⁿ⁻¹.

  • An arithmetic sequence has first term aa and common difference dd: nth term =a+(n−1)d= a + (n−1)d.

Algebra · straight-line graphs

Gradient measures steepness

  • Gradient = change in yy ÷ change in xx ("rise over run").
m=x2​−x1​y2​−y1​​m = (y₂ − y₁)/(x₂ − x₁)
  • Uphill from left to right: positive. Downhill: negative. Horizontal: 0.
  • The bigger the gradient (ignoring its sign), the steeper the line.
  • "Rise 1 for every 12 along" is a gradient of 121​1/12.
  • Foundation: read the gradient from a graph. Higher: calculate it from two given coordinates, as in the worked example below.
Algebra · straight-line graphs

The equation y=mx+cy = mx + c

  • In y=mx+cy = mx + c, mm is the gradient and cc is the yy-intercept: the line crosses the yy-axis at (0,c)(0, c).
  • Rearrange to y=…y = … first: 2y=6x−42y = 6x − 4 gives y=3x−2y = 3x − 2, so m=3m = 3 and c=−2c = −2.
  • To plot: make a table of values (three or more xx values), plot the points, rule the line.
  • y=ky = k is a horizontal line; x=kx = k is a vertical line.
  • Lines may be given as ax+by=cax + by = c: 3x+2y=53x + 2y = 5 rearranges to y=−1.5x+2.5y = −1.5x + 2.5.

Algebra · graphs of functions

Lines and parabolas

  • A linear graph y=mx+cy=mx+c is a straight line: gradient mm, crossing the yy-axis at (0,c)(0, c).
  • A quadratic graph y=ax2+bx+cy=ax²+bx+c is a parabola: U-shaped if a>0a>0, ∩-shaped if a<0a<0.
  • The roots are where the curve crosses the xx-axis (y=0y=0). The yy-intercept is at (0,c)(0, c).
  • The turning point lies on the line of symmetry, halfway between the roots.

Algebra · functions

Function notation (Higher)

  • A function turns each input into one output. f(x)=3x−5f(x) = 3x − 5 means "multiply by 3, then subtract 5".
  • f(4)f(4) means the output when the input is 4: f(4)=3×4−5=7f(4) = 3 × 4 − 5 = 7.
  • Solving f(x)=13f(x) = 13 means finding the input: 3x−5=133x − 5 = 13, so x=6x = 6.
  • Composite function: fg(x)fg(x) means f(g(x))f(g(x)). Do gg first, then ff.
  • You may also see f:x↦3x−5f: x mapsto 3x − 5, read "ff maps xx to 3x−53x − 5".

Algebra · functions

Domain and range (Higher)

  • The domain is the set of inputs allowed; the range is the set of outputs.
  • Exclude any input that would mean dividing by zero: f(x)=x−21​f(x) = 1/(x − 2) needs x=2x ≠ 2.
  • Exclude any input that would mean the square root of a negative: g(x)=x−3​g(x) = √(x − 3) needs x≥3x ≥ 3.
  • h(x)=x2+1h(x) = x² + 1 for all xx has range h(x)≥1h(x) ≥ 1, because x2x² is never negative.

Algebra · real-life graphs

Distance–time graphs

  • The gradient of a distance–time graph is the speed: distance ÷ time.
  • Steeper means faster. A horizontal line means stopped.
  • Where two graphs cross, the two objects are at the same place at the same time. If the lines do not have the same gradient there, one is overtaking the other.
  • Use the units on the axes: metres per minute, km/h, m/s.

Gradient of a curve (Higher)

  • On a curve the gradient changes. Draw a tangent: a straight line that just touches the curve at the point.
  • The gradient of the tangent is the instantaneous rate of change there, e.g. the speed at that moment on a distance–time graph.
  • Pick two points far apart on the tangent: gradient = change in yy ÷ change in xx.

Algebra · differentiation

Stationary points (Higher)

  • At a stationary point (turning point) the gradient is zero: solve dxdy​=0dy/dx = 0, then find yy.
  • Maximum: the gradient goes positive, zero, negative. Minimum: negative, zero, positive.
  • Decide which is which from the shape of the graph: a cubic with positive x3x³ term rises, falls, then rises, so its left turning point is the maximum.
  • Edexcel IGCSE expects you to use the general shape of the graph.

Recap

Big ideas

  • A linear sequence adds the same amount each time; its nth term is (difference)×n× n + adjustment.
  • A geometric sequence multiplies by the same amount each time, so it grows much faster.
  • Higher: an arithmetic sequence has nth term a+(n−1)da + (n−1)d and sum Sn​=2n​(2a+(n−1)d)Sₙ = n/2(2a + (n−1)d).
  • Gradient = change in yy ÷ change in xx; in y=mx+cy = mx + c, mm is the gradient and (0,c)(0, c) the yy-intercept.
  • To find a line's equation: gradient first, then substitute a point to find cc.
