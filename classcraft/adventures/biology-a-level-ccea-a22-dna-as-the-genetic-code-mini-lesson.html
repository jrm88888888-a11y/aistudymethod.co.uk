Mission 1

Mission 1: DNA has only four letters. How can a gene spell out a protein built from twenty different building blocks?

Make a guess: DNA has only four letters. How can a gene spell out a protein built from twenty different building blocks?

Mission 1

What is a gene?

  • A gene is a sequence of bases on DNA that codes for the amino acid sequence of a polypeptide.
  • Each gene sits at a fixed position on a chromosome: its locus.
  • Different versions of a gene (alleles) sit at the same locus on the two homologous chromosomes.
  • Say: "a gene codes for a polypeptide" — not: "a gene codes for a characteristic".
Mission 1

Why groups of three?

  • DNA has 4 bases. Polypeptides use 20 amino acids.
  • One base per amino acid: 4 codes. Two bases: 4² = 16. Too few.
  • Three bases: 4³ = 64 codes. Enough for all 20.
  • So a sequence of three bases, a base triplet, codes for one amino acid. This is the genetic code.
  • On mRNA, each triplet is a codon. The sequence is read in codons.
  • 61 codons code for amino acids; 3 are stop codons.
Quick check
?Why does the genetic code use codons of three bases rather than two?
Mission 1

Features of the code

  • Non-overlapping: each base belongs to one triplet only. Triplets are read one after another.
  • Degenerate: most amino acids have more than one codon. Glycine: GGU, GGC, GGA, GGG.
  • AUG is the start codon. It also codes for methionine.
  • Stop codons (UAA, UAG, UGA) code for no amino acid.
  • Say: "degenerate: several codons, one amino acid" — not: "one codon, several amino acids".
Quick check
?The genetic code is described as degenerate. What does this mean?
Mission 1

Worked example: reading the code

mRNA: AUGGCUUGGAAAUAGCC

  • Find the start codon: AUG.
  • Split into triplets from there: AUG | GCU | UGG | AAA | UAG | CC
  • Look up each codon in the table: Met – Ala – Trp – Lys – stop.
  • Stop at the stop codon. The polypeptide has 4 amino acids.
  • Exams give you the codon data you need. You do not learn codons by heart.

Mission 1

Coding and non-coding DNA

  • In eukaryotes, much of the DNA does not code for polypeptides. In humans, only about 1–2% does.
  • Exons: sequences within a gene that code for amino acids.
  • Introns: non-coding sequences between exons. They are removed after transcription.
  • Say: "introns are non-coding" — not: "introns are useless".
Mission 1

One gene, one polypeptide

  • Beadle and Tatum (1941) made mutants of the mould Neurospora. Each mutant could not make one nutrient.
  • Each such mutant lacked one enzyme, controlling one step in a pathway. They proposed one gene – one enzyme.
  • Many proteins contain several different polypeptides (haemoglobin has α and β chains), each from its own gene.
  • So it was refined to one gene – one polypeptide.
  • Enzymes link genes to phenotype: gene → enzyme → one step in a pathway → product → characteristic.
  • Exceptions came later: genes for functional RNA, and one gene giving several polypeptides.

Mission 2

Mission 2: Your DNA never leaves the nucleus. So how do its instructions reach the place where proteins are made?

Make a guess: Your DNA never leaves the nucleus. So how do its instructions reach the place where proteins are made?

Mission 2

Transcription comes first

  • Transcription: making an RNA copy of a gene, using one DNA strand as a template.
  • It is the first stage of gene expression. Translation comes next.
  • In eukaryotes, the mRNA leaves the nucleus through a nuclear pore. The DNA stays behind.
Mission 2

Transcription, step by step

  • RNA polymerase binds at the start of a gene. The DNA unwinds; hydrogen bonds between bases break.
  • Only one strand, the template strand, is read.
  • Free RNA nucleotides pair with exposed template bases: A–U, T–A, C–G, G–C. Hydrogen bonds hold each pair.
  • RNA polymerase joins adjacent RNA nucleotides with phosphodiester bonds, building the sugar–phosphate backbone.
  • The RNA separates from the template. The DNA rewinds.
  • Say: "RNA polymerase joins adjacent RNA nucleotides" — not: "RNA polymerase pairs the bases". Base pairs form by hydrogen bonding.
Quick check
?A section of the DNA template strand of a gene has the base sequence TACGCAT. What is the base sequence of the RNA transcribed from this section?
Mission 2

Worked example: three sequences

  • Template strand: T A C G G A T C
  • mRNA (complementary to the template): A U G C C U A G
  • Coding strand (paired with the template): A T G C C T A G
  • So mRNA = the coding strand, with U in place of T.
  • mRNA is a single strand. Its sugar is ribose. It is a copy of one gene, so it is short.
  • Its bases are read in triplets: codons.
Quick check
?During transcription, what holds each RNA nucleotide in position against the DNA template strand while it is being added to the growing RNA?
Mission check

?α-Amanitin, a toxin from the death cap mushroom, blocks the RNA polymerase that makes mRNA in eukaryotic cells. It has no effect on DNA polymerase or on ribosomes. Which prediction about liver cells exposed to it is correct?

The DNA stays put. RNA polymerase makes a temporary, complementary copy of one gene, and that copy carries the message out. Stop RNA polymerase and the message stops.

Mission 3

Mission 3: A ribosome never sees a single amino acid's name. So how does it build the right protein?

Make a guess: A ribosome never sees a single amino acid's name. So how does it build the right protein?

Mission 3

From gene to ribosome

  • DNA holds the genetic information. In eukaryotic cells it stays in the nucleus.
  • mRNA carries a copy of one gene's information to the ribosomes in the cytoplasm.
  • Translation: the base sequence of mRNA is used to build the amino acid sequence of a polypeptide.
  • The mRNA is read in codons: three bases = one amino acid (or a stop signal).
  • Amino acids are not made from the bases. They already float in the cytoplasm.
  • Say: "translation makes a polypeptide on a ribosome" — not: "the ribosome converts bases into amino acids".
Mission 3

Two RNAs, two shapes

  • mRNA: a single, linear strand; hundreds to thousands of nucleotides; a run of codons. No folded clover-leaf.
  • tRNA: a single strand of about 80 nucleotides, folded into a clover-leaf shape.
  • The fold is held by hydrogen bonds between complementary bases in the same strand.
  • One loop carries the anticodon: three bases.
  • The 3′ end is the amino acid attachment site. Each tRNA carries one specific amino acid.
Mission 3

The ribosome

  • Made of rRNA and protein, in two subunits: small and large.
  • The small subunit binds the mRNA.
  • The large subunit holds two tRNAs at the same time.
  • rRNA gives the ribosome its shape and catalyses peptide bond formation.
  • The two tRNA sites: peptidyl (P) site holds the growing chain; aminoacyl (A) site takes the next tRNA.
Quick check
?A cell contains many different kinds of tRNA molecule. What is the role of a tRNA during translation?
Mission 3

Codon meets anticodon

  • The anticodon is complementary to the codon: A–U, U–A, G–C, C–G.
  • RNA has uracil, not thymine. So codon AUG pairs with anticodon UAC.
  • Codon and anticodon are held by hydrogen bonds: weak, so the tRNA can leave later.
  • The ribosome checks only this pairing. It never checks the amino acid.
  • Say: "complementary to the codon" — not: "the same as the codon".
Mission 3

Elongation, one codon at a time

  • (1) Two tRNAs sit on the ribosome, each paired with its codon.
  • (2) A peptide bond forms between their amino acids, by condensation. The chain now hangs on the second tRNA.
  • (3) The ribosome moves one codon along the mRNA. The empty tRNA leaves.
  • (4) The next tRNA pairs with the newly exposed codon. Repeat.
  • In site terms: the new tRNA enters the A site; the chain moves onto it; the ribosome shifts so that tRNA is now in the P site.
Quick check
?An antibiotic stops the ribosome from moving along the mRNA but does not affect the binding of tRNAs or the formation of peptide bonds. What effect will this have on translation of an mRNA?
Mission 3

Start, stop and the energy bill

  • Start codon AUG: translation begins here. AUG also codes for methionine, the first amino acid.
  • Stop codons (UAA, UAG, UGA): no tRNA pairs with them. The finished polypeptide is released.
  • Many ribosomes can translate one mRNA at once, so many copies of the polypeptide are made quickly.
Mission 3

Worked example: decoding a gene

  • Template DNA strand: 3′–TAC AAG CCT TTC ACT–5′.
  • Step 1. mRNA is complementary to the template, with U for T: AUG UUC GGA AAG UGA.
  • Step 2. Read from AUG in threes. Use the table: AUG Met · UUC Phe · GGA Gly · AAG Lys · UGA stop.
  • Step 3. Polypeptide: Met–Phe–Gly–Lys. Four amino acids; the stop codon adds none.
  • Step 4. Anticodons used (each written 3′→5′): UAC, AAG, CCU, UUC. None for UGA.
  • Notice: the anticodons have the template's sequence, with U for T.
Quick check
?The coding region of an mRNA, from the first nucleotide of the start codon to the last nucleotide of the stop codon, is 903 nucleotides long. How many amino acids does the polypeptide translated from this region contain?

  • In each tube, one amino acid (or one group) was radioactive. They measured radioactivity built into protein.

Mission check

?In a test tube translation system, the tRNAs with the anticodon 3′-ACG-5′ normally carry the amino acid cysteine, and they are the only tRNAs in the system that pair with the codon 5′-UGC-3′. Before translation, the cysteine attached to these tRNAs is chemically changed into a different amino acid, alanine; the tRNAs themselves are unchanged. An mRNA containing the codon 5′-UGC-3′ is then translated. Which prediction about the polypeptide made is correct?

The ribosome reads codons, never amino acids. The tRNA is the adapter that links the two, so whatever it carries goes in.

Mission 4

Mission 4: Nearly every cell in your body carries the same genes. So why doesn't a skin cell act like a nerve cell?

Make a guess: Nearly every cell in your body carries the same genes. So why doesn't a skin cell act like a nerve cell?

Mission 4

One genome, many cell types

  • Almost every cell in a body carries the same genome.
  • Each cell uses only some of its genes. Which ones decides what the cell becomes.
  • Gene expression: transcription → translation → the protein does its job.
  • Transcription is the main switch. No transcription: no mRNA, no protein.
Quick check
?Developing red blood cells produce large amounts of the beta chain of haemoglobin, but liver cells produce none, although both cell types contain the gene. Which statement explains the difference?
Mission 4

Epigenetics: switching without rewriting

  • Epigenetics: heritable changes in gene expression without any change to the base sequence of DNA.
  • Chemical tags on the DNA, and on the histone proteins it wraps around, turn genes down or up.
  • Tags can stay in place through mitosis: daughter cells keep the same genes switched off.
  • CCEA's term: epigenetic changes are mitotically heritable.
  • The environment can change the tags (more in the next mission).
Mission 4

Methyl groups and histones

  • (1) DNA methylation: methyl groups (–CH3) are added to cytosine bases, often in a gene's promoter.
  • Methylated promoter → transcription repressed → gene silenced.
  • Transcription factors and RNA polymerase can no longer bind the promoter.
  • (2) Loosely wound DNA can be transcribed; tightly wound DNA cannot. Acetyl groups on histones loosen the winding.
  • Decreased acetylation of histones → DNA packed tightly → transcription inhibited.
  • Say: "methylation silences the gene; its base sequence is unchanged" — not: "methylation mutates the gene".
Quick check

Quick check

Mission check

?In some plants, gene F codes for a protein that stops the plant flowering. After several weeks of cold, the histones around gene F are modified and gene F stops being transcribed. When the weather warms, the new cells made by mitosis in the growing shoot also do not transcribe gene F, and the plant flowers. The base sequence of gene F is unchanged. Which statement explains these observations?

A few weeks of cold, a gene switched off, and a memory carried through every new cell. No gene was changed.

Mission 5

Mission 5

The environment changes the tags

  • Diet, stress, chemicals and pollution can add or remove epigenetic tags.
  • Changed tags → changed gene expression → changed phenotype. The base sequence stays the same.
  • Tags also change as a person ages, and differ between tissues and even between cells of one tissue.
  • Say: "the environment altered gene expression" — not: "the environment mutated the genes".
Quick check
?Blood cells from people living in a city with high levels of particulate air pollution were compared with blood cells from people living in an area with clean air. The pattern of methyl tags on the DNA of several genes differed between the two groups, but the base sequences of those genes were the same. Which conclusion is best supported by these findings?
Mission 5

Twins: one genome, two lives

  • Monozygotic (identical) twins come from one zygote: the same genome.
  • So a difference between them in epigenetic tags cannot be caused by their genes.
  • Researchers compare tags in young and old pairs, and in pairs who live together or apart.

Mission check

?Female honeybee larvae in a hive are genetically alike. Larvae fed only on royal jelly develop into fertile queens; larvae switched to a diet of worker jelly develop into smaller, sterile workers. Which explanation is consistent with the understanding of gene expression?

Twins, bees, polluted air: the same genome can be read in different ways, and the environment helps decide which.

Recap

The big ideas

Mission 1

  • A gene is a base sequence coding for a polypeptide's amino acid sequence; it has a fixed locus.
  • The code is a triplet code, read in codons: degenerate and (nearly) universal.
  • It is also non-overlapping: each base is read in one triplet only.

Mission 2

  • RNA polymerase reads one DNA strand (the template) and joins complementary RNA nucleotides (A–U, C–G) to make mRNA.
  • mRNA has the coding strand's sequence with U for T; the DNA template is unchanged.

Mission 3

  • mRNA codons pair with complementary tRNA anticodons on the ribosome; each tRNA brings its amino acid, and peptide bonds join them one codon at a time from AUG to a stop codon.

Mission 4

  • Every cell carries the same genome; cell types differ in which genes are transcribed.
  • Epigenetic tags (DNA methylation, histone modification) change expression without changing the sequence, and pass through mitosis.

Mission 5

  • The environment can change epigenetic tags, so genetically identical cells or organisms can express different genes; the base sequence is unchanged.
