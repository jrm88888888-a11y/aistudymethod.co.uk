Mission 1

Mission 1: DNA has only four letters. How can a gene spell out a protein built from twenty different building blocks?

Make a guess: DNA has only four letters. How can a gene spell out a protein built from twenty different building blocks?

Mission 1

Why groups of three?

  • DNA has 4 bases. Polypeptides use 20 amino acids.
  • One base per amino acid: 4 codes. Two bases: 4² = 16. Too few.
  • Three bases: 4³ = 64 codes. Enough for all 20.
  • On mRNA, each triplet is a codon. The sequence is read in codons.
  • 61 codons code for amino acids; 3 are stop codons.
Mission 1

Features of the code

  • Degenerate: most amino acids have more than one codon. Glycine: GGU, GGC, GGA, GGG.
  • Many amino acids are encoded by more than one codon.
  • Universal: the same codon codes for the same amino acid in almost all organisms.
  • AUG is the start codon. It also codes for methionine.
  • Stop codons (UAA, UAG, UGA) code for no amino acid.
  • Say: "degenerate: several codons, one amino acid" — not: "one codon, several amino acids".

  • Stop at the stop codon. The polypeptide has 4 amino acids.
  • Recall only AUG. Use the genetic code chart for the rest.

Mission 1

One code for (almost) all life

  • Bacteria given the coding sequence for human insulin (no introns) make the same polypeptide chains as human cells. They read the codons the same way.
  • A few small variants exist (e.g. in mitochondria), so the code is nearly universal.
  • Chemistry does not force which codon means which amino acid: other codes can work, and slightly different ones exist (e.g. in mitochondria).
  • So a shared code is best explained by common ancestry of all living things.

Mission 2

Mission 2: Your DNA never leaves the nucleus. So how do its instructions reach the place where proteins are made?

Make a guess: Your DNA never leaves the nucleus. So how do its instructions reach the place where proteins are made?

Mission 2

Transcription comes first

  • Transcription: making an RNA copy of a gene, using one DNA strand as a template.
  • It is the first stage of gene expression. Translation comes next.
  • In eukaryotes, the mRNA leaves the nucleus through a nuclear pore. The DNA stays behind.
  • RNA polymerase uses a single template strand of DNA to direct which bases go into the new RNA.
Mission 2

Transcription, step by step

  • RNA polymerase binds at the start of a gene. The DNA unwinds; hydrogen bonds between bases break.
  • Only one strand, the template strand, is read.
  • Free RNA nucleotides pair with exposed template bases: A–U, T–A, C–G, G–C. Hydrogen bonds hold each pair.
  • RNA polymerase joins adjacent RNA nucleotides with phosphodiester bonds, building the sugar–phosphate backbone.
  • The RNA separates from the template. The DNA rewinds.
  • Say: "RNA polymerase joins adjacent RNA nucleotides" — not: "RNA polymerase pairs the bases". Base pairs form by hydrogen bonding.
Quick check
?Which statement describes how the DNA of a gene is used during transcription?
Mission 2

Worked example: three sequences

  • Template strand: T A C G G A T C
  • mRNA (complementary to the template): A U G C C U A G
  • Coding strand (paired with the template): A T G C C T A G
  • So mRNA = the coding strand, with U in place of T.
  • mRNA is a single strand. Its sugar is ribose. It is a copy of one gene, so it is short.
  • Its bases are read in triplets: codons.
Mission check

?α-Amanitin, a toxin from the death cap mushroom, blocks the RNA polymerase that makes mRNA in eukaryotic cells. It has no effect on DNA polymerase or on ribosomes. Which prediction about liver cells exposed to it is correct?

The DNA stays put. RNA polymerase makes a temporary, complementary copy of one gene, and that copy carries the message out. Stop RNA polymerase and the message stops.

Mission 3

Which way does transcription run?

  • RNA polymerase adds each nucleotide to the 3′ end of the growing RNA.
  • So RNA is made 5′ → 3′.
  • The template is antiparallel, so it is read 3′ → 5′.
  • The RNA has the same sequence and direction as the coding strand (U for T).
  • Say: "made 5′ to 3′, template read 3′ to 5′" — not: "both run 5′ to 3′".

Mission 3

Starting at the promoter

  • The promoter is a DNA sequence near the start of a gene. RNA polymerase binds there.
  • In eukaryotes, proteins called transcription factors bind to the promoter. Then RNA polymerase can bind and start.
  • Cell types differ in their transcription factors, so they switch on different genes.
  • Enhancers are other DNA sequences that bind transcription factors.
  • Promoters and enhancers can be upstream or downstream of the transcription start site.
  • The promoter is not transcribed into the mRNA.
  • Say: "promoters are DNA; transcription factors are proteins" — not: "a promoter is a protein".
Quick check
?Which statement describes promoters and enhancers?
Mission 3

From pre-mRNA to mature mRNA

  • In eukaryotes, the whole gene, introns included, is transcribed. The product is pre-mRNA.
  • Splicing: the introns are removed and the exons are joined.
  • A GTP cap is added to the 5′ end: it helps the ribosome recognize the mRNA.
  • A poly-A tail is added to the 3′ end: it makes the mRNA more stable.
  • The mature mRNA leaves the nucleus.
  • Say: "introns are removed from the RNA" — not: "introns are cut out of the gene's DNA".

Mission 3

One gene, several proteins

  • Exons from one pre-mRNA can be joined in different combinations: alternative splicing.
  • So one gene can code for several different polypeptides.
  • Different cell types can splice the same gene differently.
  • Example: exons 1 and 4 always kept; exons 2 and 3 each kept or not. That gives 2 × 2 = 4 different mRNAs.
  • Humans have about 20 000 protein-coding genes, yet make far more different polypeptides.
  • Most human genes with several exons are alternatively spliced.

?A eukaryotic gene has four exons and three introns. In one family, a single-base change at the edge of intron 2 means intron 2 is no longer recognized for splicing. All other splicing is normal. Which prediction is correct?

Splicing decides which parts of the first RNA copy reach the ribosome. Keep one intron by mistake and the message changes.

Mission 4

Mission 4: How does a ribosome find the right place to start reading a message?

Make a guess: How does a ribosome find the right place to start reading a message?

Mission 4

Where translation happens

  • Translation happens on ribosomes in the cytoplasm of every cell.
  • Eukaryotes: ribosomes are free in the cytosol or bound to the cytoplasmic surface of the rough ER.
  • Polypeptides made on rough ER ribosomes enter the ER; many become membrane or secreted proteins.
  • Prokaryotes: no ER, no nucleus. All ribosomes are free in the cytoplasm.
  • Say: "ribosomes on the rough ER make the polypeptide" — not: "the ER membrane makes proteins".
Mission 4

One direction only

  • Each RNA strand has a 5′ end and a 3′ end.
  • The ribosome reads mRNA 5′ → 3′.
  • So the codon nearest the 5′ end is translated first.
  • The start codon AUG sets the reading frame: from there, every three bases is one codon.
  • Say: "the ribosome moves along mRNA 5′ → 3′" — not: "it reads mRNA 3′ → 5′, like the template".
Mission 4

Bacteria don't wait

  • Eukaryotes: mRNA is made in the nucleus, then leaves before translation.
  • Prokaryotes: no nuclear envelope. Ribosomes attach to the 5′ end of the mRNA while RNA polymerase is still making the rest.
  • Transcription and translation happen at the same time.
  • Several ribosomes can translate one mRNA together (a polysome).
  • Result: a bacterium can make a newly needed protein within minutes.
Quick check
?When a hypothetical species of bacterium is moved to a new food source, molecules of a newly needed enzyme can be detected sooner after transcription of its gene begins than in a comparable eukaryotic cell. Which explanation best accounts for this difference?
Mission 4

Starting at AUG

  • rRNA in the ribosome interacts with the mRNA at the start codon, AUG.
  • A tRNA carrying methionine pairs with AUG. Then the rest of the ribosome assembles.
  • Elongation: tRNAs bring amino acids codon by codon; each is transferred to the growing chain.
  • Termination: at a stop codon no tRNA pairs. The new polypeptide is released.
  • Every step happens in order: no initiation, no new polypeptide.
Quick check
?Which statement correctly describes how translation of an mRNA ends?
Mission 4

One code for nearly all life

  • Nearly every organism reads codons the same way: AUG = methionine in bacteria, plants and people.
  • A few small exceptions exist (for example, in mitochondria), so the code is near-universal.
  • A shared code is best explained by inheritance from a common ancestor.
  • It is also why a bacterium can make a human protein from a human coding sequence.
Quick check
?When a DNA copy of a jellyfish gene's mature mRNA (with no introns) is inserted into bacteria, the bacteria make a protein with the same amino acid sequence as the jellyfish protein. Which statement best explains how this result relates to the evolution of life?
Mission check

?A hypothetical drug acts on ribosomes that are not attached to an mRNA, preventing them from assembling on an mRNA at its start codon. Which prediction is most likely shortly after the drug is added to a culture of eukaryotic cells?

Every polypeptide starts where the ribosome assembles at AUG. Block that step and production stops as the chains in progress finish.

Mission 5

Mission 5: A gene has already been copied into a message. Can the cell still stop its protein being made?

Make a guess: A gene has already been copied into a message. Can the cell still stop its protein being made?

Mission 5

Control after transcription

  • Transcription is not the last switch.
  • After it, the mRNA can be edited, blocked or broken down early.
  • Splicing can give one gene several proteins.
  • How long each mRNA lasts sets how much protein it makes.
  • Small RNA molecules can stop an mRNA being translated.
Mission 5

Splicing: introns out, exons joined

  • In eukaryotes, transcription makes primary mRNA (pre-mRNA): exons and introns.
  • Splicing removes the introns and joins the exons → mature mRNA.
  • A GTP cap is also added (helps ribosomes recognize the mRNA) and a poly-A tail (makes the mRNA more stable).
  • Only mature mRNA leaves the nucleus to be translated.
  • Say: "introns are removed from the mRNA" — not: "introns are cut out of the gene".
Mission 5

Alternative splicing: one gene, several proteins

  • (1) Exons can be joined in different combinations.
  • (2) Different mature mRNAs → different polypeptides from one gene.
  • Example: one human gene gives calcitonin (a hormone) in thyroid cells and CGRP (a signaling peptide) in neurones. Different exons are kept in each.
  • So about 20 000 human genes code for many more proteins.
  • Say: "different exons are spliced together" — not: "the gene mutates to make each version".
Mission 5

How long does an mRNA last?

  • Nucleases in the cytoplasm break mRNA down.
  • In human cells an mRNA may last from minutes to days.
  • While it lasts, each mRNA is translated many times.
  • Long-lived mRNA → much protein. Short-lived mRNA → protein level can change quickly.
  • The poly-A tail protects mRNA, making it more stable.
  • So controlling mRNA breakdown regulates translation.
Quick check
?Two genes in a human cell are transcribed at the same rate. mRNA from gene P is broken down by nucleases about 10 minutes after it is made; mRNA from gene Q persists for about two days. Assume both mRNAs are translated at the same rate while they persist. Which statement is correct?
Mission 5

RNA interference

  • RNA interference (RNAi): small RNA molecules stop a specific mRNA being translated.
  • (1) A small RNA, about 21 nucleotides long, joins a protein complex.
  • (2) Its bases are complementary to part of a target mRNA, so it base-pairs with it.
  • (3) siRNA: exact match → the mRNA is cut and broken down. miRNA: partial match → translation blocked (or the mRNA broken down); one miRNA can act on many mRNAs.
  • The gene is still transcribed. Less protein is made.
  • Say: "the small RNA is complementary to the mRNA" — not: "the small RNA changes the gene".
Quick check

Mission 6

The HIV particle

  • HIV is one example of a retrovirus.
  • Genome: two copies of single-stranded RNA.
  • Enzymes packed inside: reverse transcriptase (and others).
  • Capsid: a protein coat around the RNA.
  • Envelope: a lipid bilayer, taken from the host cell membrane.
  • Attachment proteins (glycoproteins) stick out of the envelope.
Mission 6

Inside a helper T cell

  • (1) The virus attaches to a host cell (for HIV, a helper T cell of the immune system), and its genome enters.
  • (3) Reverse transcriptase copies the viral RNA into DNA.
  • (4) The viral DNA integrates into the host genome.
  • (5) The host cell transcribes and translates it: viral RNA and proteins.
  • (6) New particles assemble and bud out, wrapped in host membrane.
Quick check

Mission check

?A drug stops retroviral DNA from being inserted into the host genome. Reverse transcriptase still works. Cells treated with the drug are exposed to a retrovirus. Which result is predicted?

A retrovirus becomes a factory only once its DNA sits in the host genome. Block that step and the cell makes no new virus.

Recap

The big ideas

Mission 1

  • The code is a triplet code, read in codons: degenerate and (nearly) universal.
  • A shared code is evidence that all life has a common ancestor.

Mission 2

  • RNA polymerase reads one DNA strand (the template) and joins complementary RNA nucleotides (A–U, C–G) to make mRNA.
  • mRNA has the coding strand's sequence with U for T; the DNA template is unchanged.

Mission 3

  • RNA is made 5′ → 3′ from a template read 3′ → 5′, starting where transcription factors and RNA polymerase bind the promoter.
  • Eukaryotic pre-mRNA is spliced: introns removed, exons joined.
  • A GTP cap aids ribosome recognition; a poly-A tail adds stability.
  • Alternative splicing lets one gene code for several polypeptides.

Mission 4

  • Translation starts when rRNA interacts with mRNA at AUG and ends with release at a stop codon; in prokaryotes it starts while the mRNA is still being made, and the near-universal code points to common ancestry.

Mission 5

  • Alternative splicing joins different exons, so one gene can give several polypeptides.
  • The longer an mRNA lasts before nucleases break it down, the more protein it makes.
  • In RNA interference, a small RNA base-pairs with a complementary mRNA, which is cut or blocked: less protein, same gene.

Mission 6

  • Retroviruses copy RNA into DNA with reverse transcriptase; the DNA integrates into the host genome and is expressed to make new viruses.
