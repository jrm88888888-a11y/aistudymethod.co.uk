Mission 1

Mission 1: DNA has only four letters. How can a gene spell out a protein built from twenty different building blocks?

Make a guess: DNA has only four letters. How can a gene spell out a protein built from twenty different building blocks?

Mission 1

What is a gene?

  • A gene is a sequence of bases on DNA that codes for the amino acid sequence of a polypeptide.
  • Say: "a gene codes for a polypeptide" — not: "a gene codes for a characteristic".
Mission 1

Why groups of three?

  • DNA has 4 bases. Polypeptides use 20 amino acids.
  • One base per amino acid: 4 codes. Two bases: 4² = 16. Too few.
  • Three bases: 4³ = 64 codes. Enough for all 20.
  • So a sequence of three bases, a base triplet, codes for one amino acid. This is the genetic code.
  • On mRNA, each triplet is a codon. The sequence is read in codons.
  • 61 codons code for amino acids; 3 are stop codons.
  • A strand n bases long can have 4ⁿ sequences: for 10 bases, 1 048 576. DNA can be any length, so its capacity to store information is limitless.
Quick check
?Why does the genetic code use codons of three bases rather than two?
Mission 1

Features of the code

  • Degenerate: most amino acids have more than one codon. Glycine: GGU, GGC, GGA, GGG.
  • Universal: the same codon codes for the same amino acid in almost all organisms.
  • AUG is the start codon. It also codes for methionine.
  • Stop codons (UAA, UAG, UGA) code for no amino acid.
  • Say: "degenerate: several codons, one amino acid" — not: "one codon, several amino acids".
Quick check
?The genetic code is described as degenerate. What does this mean?
Mission 1

Worked example: reading the code

mRNA: AUGGCUUGGAAAUAGCC

  • Find the start codon: AUG.
  • Split into triplets from there: AUG | GCU | UGG | AAA | UAG | CC
  • Look up each codon in the table: Met – Ala – Trp – Lys – stop.
  • Stop at the stop codon. The polypeptide has 4 amino acids.
  • Use the table of mRNA codons; do not take the complement first.

Mission 1

One code for (almost) all life

  • Bacteria given the coding sequence for human insulin (no introns) make the same polypeptide chains as human cells. They read the codons the same way.
  • A few small variants exist (e.g. in mitochondria), so the code is nearly universal.
  • Chemistry does not force which codon means which amino acid: other codes can work, and slightly different ones exist (e.g. in mitochondria).
  • So a shared code is best explained by common ancestry of all living things.
  • Evidence for LUCA (last universal common ancestor): the universal code, plus genes shared by all organisms.
  • Other early life forms probably existed, but became extinct, outcompeted by LUCA and its descendants.
Quick check
?The gene for human insulin has been inserted into bacteria, which then translate it into a polypeptide with the same amino acid sequence as the polypeptide made in human cells. Which feature of the genetic code makes this possible?
Mission 1

Coding and non-coding DNA

  • In eukaryotes, much of the DNA does not code for polypeptides. In humans, only about 1–2% does.
  • Exons: sequences within a gene that code for amino acids.
  • Introns: non-coding sequences between exons. They are removed after transcription.
  • Non-coding sequences include: regulators of gene expression (e.g. promoters), introns, telomeres (at chromosome ends), and genes for tRNA and rRNA (transcribed but never translated).
  • Say: "introns are non-coding" — not: "introns are useless".

Mission 2

Mission 2: Two animals look almost identical. How can biologists tell whether they are truly close relatives?

Make a guess: Two animals look almost identical. How can biologists tell whether they are truly close relatives?

Mission 2

Same bones, different jobs

  • Homologous structures: the same basic structure, used for different functions.
  • Pentadactyl limb: one upper bone, two lower bones, a group of wrist bones, five digits.
  • Found in a human arm, a bat wing, a whale flipper.
  • No single job needs this layout. It was inherited from a common ancestor and modified.
Mission 2

Same job, different origins

  • Analogous structures: the same function, different evolutionary origins.
  • They arise by convergent evolution: similar selection pressures favour similar forms in unrelated lineages.
  • Examples: streamlined body and fins of a shark (fish) and a dolphin (mammal); wings of birds and insects.
  • Say: "convergent: features became alike" — not: "the species are merging".
Quick check
?Sharks, which are fish, and dolphins, which are mammals, both have streamlined bodies, a dorsal fin and paddle-shaped front fins. Which statement about these features is correct?
Mission 2

  • Fewer differences → more recent common ancestor. P and Q are the closest relatives here.
  • DNA differs more than protein: some base changes do not change the amino acid.
  • Say: "P and Q share a more recent common ancestor" — not: "P evolved from Q".
Quick check
?The amino acid sequence of the same protein was compared in four species. Compared with species W, species X differs at 2 positions, species Y at 15 positions and species Z at 31 positions. Which conclusion is supported by the data?
Mission 2

Shared by all life

  • The genetic code is almost universal: the same codons code for the same amino acids in bacteria, plants and animals.
  • The code is not the only one possible: slightly different codes work (e.g. in mitochondria). Sharing one code is best explained by common ancestry of all life.
  • So a copy of a human gene, with its introns removed, can be put into a bacterium, and the bacterium makes a chain with the same amino acid sequence.
Mission 2

Why some sequences barely change

  • Conserved sequences: identical or similar across a species or group of species.
  • Highly conserved: identical or similar over long periods of evolution, e.g. histone H4 in peas and cattle.
  • Two hypotheses:
    • Functional requirement: mutations arise, but almost any change harms the product, so natural selection removes them.
    • Slower mutation rate: fewer mutations arise in that sequence.
  • Test: measure the rate of new mutations. Same rate but fewer persist → functional requirement.
Quick check
?The rate at which new mutations appear per generation was measured directly in a highly conserved gene and in a gene that is not conserved. The rates were the same, but far fewer of the new mutations in the conserved gene persisted in later generations. Which hypothesis do the data support?
Mission 2

Read the data: human chromosome 2

  • A karyogram pairs chromosomes by length, centromere position and banding pattern.
  • Humans have 46 chromosomes; chimpanzees, gorillas and orangutans have 48.
  • Human chromosome 2's banding matches two chimpanzee chromosomes placed end to end.
  • Near its middle: telomere-like sequences (normally only at chromosome ends) and a second, inactive centromere.
  • Hypothesis: two chromosomes fused in an ancestor of humans after the split from chimpanzees.
  • It is testable: it predicted features that could have been absent. They were found.
Quick check
?Human chromosome 2 contains telomere-like sequences near its middle and a second, inactive centromere region, and its banding pattern matches the two chimpanzee chromosomes formerly numbered 12 and 13 placed end to end. How well does this evidence support the hypothesis that chromosome 2 arose by fusion of two chromosomes inherited from a shared primate ancestor?
Mission check

?The marsupial mole of Australia and the golden moles of southern Africa look remarkably alike: tiny or hidden eyes, no external ears and spade-like front claws for digging. DNA comparisons place the marsupial mole closest to other Australian marsupials, and the golden moles closest to other African placental mammals. Which conclusion is best supported?

Looks can converge. Inherited structure and molecular sequences show who is really related.

Mission 3

Mission 3: How can we trust the evidence that living things have changed over time?

Make a guess: How can we trust the evidence that living things have changed over time?

Mission 3

Reading diet from fossil teeth

  • Paranthropus robustus (extinct): very large, flat molars with thick enamel, small canines, massive jaw, sagittal crest for big chewing muscles → grinding tough plants: herbivorous.
  • Homo sapiens: smaller molars, small canines, lighter jaw, no crest: unspecialised teeth for a mixed diet → omnivorous.
  • Homo floresiensis is another extinct hominid whose diet can be inferred the same way.
  • Nature of science: theories linking teeth to diet came from living mammals. They let us deduce the diet of extinct species.
Quick check
?Two hominid skulls are compared. Skull A has very large flat molars with thick enamel, small canines, a massive lower jaw and a sagittal crest for large chewing muscles. Skull B has relatively small molars, small canines little larger than the incisors, a lighter jaw and no sagittal crest. What can be deduced about the diets of the two species?
Mission 3

Selective breeding: evolution you can watch

  • Artificial selection: humans choose individuals with desired heritable traits and breed only from them, generation after generation.
  • Wild cabbage (Brassica oleracea) gave cabbage, kale, broccoli, cauliflower, kohlrabi and Brussels sprouts in a few thousand years.
  • All domestic dogs descend from wolves.
  • Differences between breeds, and between them and the wild species, show how rapidly heritable characteristics can change.
  • Artificial = deliberate human choice of traits. Unintended effects of human action (e.g. antibiotic resistance) are natural selection.
  • Breeders cannot create new alleles. They select among variation that already exists.
Quick check
?Cabbage, kale, broccoli, cauliflower, kohlrabi and Brussels sprouts were all produced from wild cabbage (Brassica oleracea) by selective breeding over the past few thousand years. What does this show about evolution?
Mission 3

How scientists test the evidence

  • Before a new claim is accepted, other scientists check it: experts review the work before publication, and other groups test it again.
  • A theory is not a guess. Evolution by natural selection predicts and explains a huge range of observations.
  • It cannot be formally proved, but it is unlikely ever to be falsified: a pragmatic truth.
Quick check
?A student says: 'Evolution by natural selection is only a theory, so it has not been proved and could easily be overturned.' Which response best evaluates this claim?
Mission check

?Whales were once thought to be most closely related to an extinct group of hoofed carnivores. DNA comparisons then placed whales closest to hippopotamuses, among the even-toed hoofed mammals. Soon after, fossils of early whales were found with an ankle bone of a shape found only in even-toed hoofed mammals. Why does this agreement strengthen confidence in the relationship?

No single fossil or sequence settles it. Confidence comes from independent evidence that keeps agreeing.

Mission 4

Mission 4: DNA can only be built in one direction, yet its two strands run opposite ways. How are both copied at once?

Make a guess: DNA can only be built in one direction, yet its two strands run opposite ways. How are both copied at once?

Mission 4

Every strand has two different ends

  • The carbons of each sugar are numbered 1′ to 5′.
  • The phosphate is on the 5′ carbon; an –OH is on the 3′ carbon.
  • In the backbone, each phosphate links the 3′ carbon of one sugar to the 5′ carbon of the next.
  • So a strand has a 5′ end (free phosphate) and a 3′ end (free –OH).
  • The two strands of a double helix are antiparallel: they run in opposite directions.
  • Direction matters for replication, transcription and translation.
Quick check
?What do the labels 5' and 3' refer to in a strand of DNA or RNA?
Mission 4

DNA polymerase adds only at the 3′ end

  • DNA polymerase links the 5′ phosphate of an incoming nucleotide to the free 3′ –OH at the end of the strand.
  • So a new strand grows only at its 3′ end: synthesis is 5′ to 3′.
  • The template is read 3′ to 5′ (the strands are antiparallel).
  • DNA polymerase cannot start a strand on a bare template. It needs a short RNA primer with a free 3′ end.
  • Say: "added at the 3′ end, so the strand grows 5′ to 3′" — not: "added at the 5′ end".
Quick check
?During replication, how does DNA polymerase add each new nucleotide to the strand it is building?
Mission 4

Leading and lagging strands

  • Helicase opens the fork in one direction. Both new strands must still grow 5′ to 3′.
  • Leading strand: its template runs 3′ to 5′ towards the fork. It is made continuously, following the fork.
  • Lagging strand: it must grow away from the fork. It is made discontinuously, in short fragments.
  • The fragments are Okazaki fragments.
  • The leading strand needs an RNA primer once; the lagging strand needs one for every fragment.
  • Both strands are made at the same fork, at the same time.
  • Say: "both strands are made 5′ to 3′; the lagging strand is made in fragments" — not: "the lagging strand is made 3′ to 5′".
Quick check
?Starting from the origin, one replication fork in a bacterium copies a 6000 base pair section of the chromosome. Okazaki fragments in this bacterium are about 1000 nucleotides long. Approximately how many RNA primers are needed at this fork?
Mission 4

The enzyme team (prokaryotes)

  • DNA primase makes each short RNA primer.
  • DNA polymerase III adds DNA nucleotides to the primer's 3′ end. It builds most of both new strands.
  • DNA polymerase I removes each RNA primer and replaces it with DNA nucleotides.
  • DNA ligase seals the last gap in the backbone, joining Okazaki fragments into one strand.
  • Order on the lagging strand: primase → DNA pol III → DNA pol I → ligase.
Quick check
?On the lagging strand, DNA polymerase III has extended an Okazaki fragment until it reaches the RNA primer of the previous fragment. Which sequence of events completes this section of the strand?
Mission 4

Proofreading

  • Now and then, a nucleotide with the wrong base is added.
  • DNA polymerase III checks the nucleotide it has just added, at the 3′ terminal.
  • A mismatch is removed from the 3′ terminal and replaced with a correctly matched nucleotide.
  • Then synthesis continues. Most errors are fixed before the next base is added.
  • Say: "DNA polymerase III proofreads as it goes" — not: "the finished molecule is checked afterwards".
Quick check
?As DNA polymerase III builds a new strand it adds a nucleotide carrying G opposite a T on the template. What happens next?
Mission check

?A hypothetical species of bacterium has a mutation that makes its DNA ligase inactive at 40 °C but not at 30 °C. Cells are moved from 30 °C to 40 °C just before a round of DNA replication begins. Which prediction about the new DNA made at 40 °C is correct?

One direction, two antiparallel strands: one strand follows the fork smoothly, the other is built backwards in pieces and stitched together.

Mission 5

Where cells keep their DNA

  • Eukaryotes keep most of their DNA in the nucleus, as several linear chromosomes.
  • Each chromosome holds one very long DNA molecule, associated with histone proteins.
Quick check
?The model represents three levels of packing of DNA in a eukaryotic chromosome. Based on the model, which statement correctly describes the role of histones?
Mission 5

Packing it in

  • Stretched out, the DNA in one human body cell is about 2 m long. The nucleus is about 6 µm across.
  • (1) DNA winds around histones.
  • (2) The wound DNA coils, and coils again.
  • This repeated coiling is supercoiling.
  • (3) Before nuclear division, each chromosome condenses: short, thick, visible, and movable without tangling.
  • Between divisions, chromosomes are less condensed, so DNA can be copied and its genes used.
  • Packing changes how tightly DNA is folded. It never changes the base sequence.
  • Say: "DNA is wound around histones" — not: "histones wrap around the DNA".
Quick check
?How is the DNA of a eukaryotic chromosome condensed before nuclear division?
Mission 5

Inside a nucleosome

  • Nucleosome: DNA wrapped around a core of eight histone proteins.
  • An additional histone, attached to the linker DNA, holds the DNA on the core.
  • Linker DNA runs from one nucleosome to the next: "beads on a string".
  • Histones are positively charged; DNA's phosphate backbone is negatively charged. They attract.
  • No covalent bonds: the DNA can be released for replication and transcription.
  • Say: "DNA is wound around a core of eight histones" — not: "nine histones in the core" or "the DNA runs through the bead".
Mission 5Skill

Molecular visualisation

IB skill: "use molecular visualisation software to study the association between the proteins and DNA within a nucleosome".

  • Open a nucleosome structure in free software, e.g. the Mol* viewer on the RCSB Protein Data Bank, entry 1KX5.
  • Colour the DNA one colour and the proteins another.
  • Rotate it: the DNA is the outer coil; the proteins form the core.
  • Count the protein chains in the core: 8.
  • If the software can colour by charge: positive side chains of the histones face the DNA's phosphates.
  • Core-particle structures such as 1KX5 show no linker histone.
Quick check
?A student uses molecular visualisation software to examine a nucleosome, colouring the DNA one colour and the proteins another. What would the student observe about the association between the DNA and the proteins?
Mission check

?Each chromatid of human chromosome 1 contains one DNA molecule about 85 mm long. When the cell divides, the condensed chromosome is about 10 µm long (illustrative round value). Which statement is correct?

One molecule, thousands of times longer than the chromosome it forms. Histones, then coil upon coil, make it fit.

Mission 6

Mission 6: Your body cells carry chromosomes in pairs. How can you tell which two belong together?

Make a guess: Your body cells carry chromosomes in pairs. How can you tell which two belong together?

Mission 6

Chromosomes come in pairs

  • Most body cells hold two sets of chromosomes: one set from each parent.
  • Two matching chromosomes form a homologous pair.
  • Homologues: same size, same genes at the same positions (loci).
  • They may carry different alleles (versions) of those genes.
  • Say: "homologous chromosomes carry the same genes" — not: "the same alleles".
Mission 6

Diploid and haploid

  • Diploid (2n): two sets of chromosomes, in homologous pairs. Most body cells.
  • Haploid (n): one set. Gametes.
  • Humans: 2n = 46 (23 pairs); gametes: n = 23.
  • Chimpanzees: 2n = 48. Numbers vary widely between plant and animal species.
  • Diploid numbers are normally even: chromosomes come in pairs.
  • A haploid cell has one copy of every gene, not half the genes.
Quick check
?Which statement about chromosome numbers is correct?
Mission 6

Karyotypes and karyograms

  • Karyotype: the number and appearance of the chromosomes in a cell.
  • Karyogram: an image of them arranged in homologous pairs, largest first.
  • Made from dividing cells (chromosomes condensed), stained and photographed.
  • Match homologues on three features: length, centromere position, banding pattern.
  • Human karyogram: 22 pairs of autosomes + the sex chromosomes, XX (female) or XY (male).
  • X and Y are not a matched pair: the Y is much smaller.
  • Say: "bands are stained regions" — not: "each band is a gene".
Mission 6

The sex chromosomes

  • Every egg carries an X.
  • Sperm carry an X or a Y, in equal numbers.
  • So the sperm decides: X sperm → XX zygote; Y sperm → XY zygote.
  • XY zygotes develop certain male-typical physical characteristics; XX zygotes, female-typical ones.
  • The X carries far more genes than the Y. Most X genes have no partner on the Y.
  • Say: "the sex chromosome in the sperm determines it" — not: "the egg" or "both equally".
Quick check
?Which statement about sex determination and the sex chromosomes in humans is correct?
Mission 6Read the data

Human chromosome 2

  • Humans: 46. Chimpanzees, gorillas and orangutans: 48.
  • Hypothesis: human chromosome 2 formed when two ancestral chromosomes fused. In chimpanzees they are still separate (numbered 12 and 13 in older schemes).
  • (1) Banding: human 2 matches chimpanzee 12 + 13 placed end to end.
  • (2) Telomere sequences, normally only at chromosome ends, sit near the middle of human 2.
  • (3) A second, inactive centromere sits where the other chromosome's centromere would be.
  • Each was predicted by fusion, and each could have been absent: the hypothesis is testable.
  • A claim that no possible observation could contradict is not testable.
Quick check
?Which observation, had it been made, would have counted against the hypothesis that human chromosome 2 formed by the fusion of two ancestral chromosomes?
Mission 6

One species, one chromosome number

  • Chromosome number is a shared trait of a species.
  • Horse: 2n = 64. Donkey: 2n = 62. Their hybrid, the mule: 32 + 31 = 63.
  • Mitosis copies and separates every chromosome, so a mule grows normally.
  • In meiosis, homologues must pair. Many of the mule's chromosomes have no partner.
  • Few viable gametes form: mules are almost always sterile.
  • So close species with different chromosome numbers rarely produce fertile offspring.
  • Say: "homologues cannot pair in meiosis" — not: "an odd number cannot divide by mitosis".
Quick check
?A horse has 64 chromosomes in its body cells and a donkey has 62. They can mate to produce a mule. Which statement correctly explains why mules are almost always sterile?
Mission 6

Genomes: shared and varied

  • Genome: all the genetic information of an organism, coding and non-coding DNA.
  • Members of a species share most of their genome.
  • Small differences, such as single-nucleotide polymorphisms (SNPs), give diversity within a species.
  • Two unrelated humans: about 1 base in 1000 differs.
  • Human vs chimpanzee: about 12 bases in 1000 differ.
  • Variation between species is much larger than variation within a species.
  • Say: "genome size is the total amount of DNA" — not: "the number of chromosomes" or "the number of genes".

Recap

The big ideas

Mission 1

  • A gene is a base sequence coding for a polypeptide's amino acid sequence; it has a fixed locus.
  • The code is a triplet code, read in codons: degenerate and (nearly) universal.
  • A shared code is evidence that all life has a common ancestor.

Mission 2

  • Homologous structures share an origin but differ in function; analogous structures share a function but arose separately by convergent evolution.
  • Fewer differences in DNA or protein sequences mean a more recent common ancestor.
  • A near-universal genetic code points to common ancestry of all life.

Mission 3

  • Selective breeding changes heritable characteristics fast, showing evolution can be rapid; it reduces genetic variation.
  • Evidence is trusted after scrutiny by other scientists and independent confirmation; a theory is a well-tested explanation, not a guess.

Mission 4

  • DNA polymerase adds nucleotides only to a 3′ end, so every strand grows 5′ to 3′ and needs an RNA primer to start.
  • Leading strand: continuous, one primer. Lagging strand: fragments, one primer each, joined by ligase.
  • Primase makes primers; DNA pol III extends and proofreads; DNA pol I replaces primers with DNA; ligase seals.

Mission 5

  • A chromosome is a long DNA molecule packed with histones; it condenses before nuclear division without any change to its base sequence.
  • Nucleosome: DNA wound around eight histones, held by an additional histone on the linker DNA.

Mission 6

  • Homologous chromosomes carry the same genes at the same loci, one set from each parent; they may carry different alleles.
  • Diploid = two sets (humans 46), haploid = one set (23); karyograms pair homologues by length, centromere position and banding.
  • Chromosome 2 fusion explains 46 vs 48; genome size is total DNA and does not track complexity.
  • Different chromosome numbers stop homologues pairing in a hybrid's meiosis, so hybrids such as mules are almost always sterile.
