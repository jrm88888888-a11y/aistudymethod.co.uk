HL calculus · differential equations and slope fields

Turning words into a differential equation

  • "The rate of change of PP" is dtdP​dP/dt.
  • "Proportional to" means "equals a constant kk times". "Decreasing" makes the rate negative: write −k−k with k>0k > 0.
  • Example: a drink cools at a rate proportional to the difference between its temperature TT and room temperature 20 °C: dtdT​=−k(T−20)dT/dt = −k(T − 20).
  • The general solution contains an arbitrary constant. An initial condition fixes it, giving a particular solution.

Separation of variables

  • If dxdy​=f(x)g(y)dy/dx = f(x) g(y), collect each variable on its own side and integrate:
∫g(y)1​dy=∫f(x)dx∫ 1/(g(y)) dy = ∫ f(x) dx
  • One constant of integration is enough; put it on the xx side.
  • The key model: dxdy​=kydy/dx = ky gives ln∣y∣=kx+cln |y| = kx + c, so y=Aekxy = Ae^kx, an exponential model.

HL calculus · differential equations and slope fields

Slope fields

  • A slope field draws a short segment at each grid point (x,y)(x, y) with gradient dxdy​dy/dx there.
  • A solution curve follows the segments; each initial point gives one curve.
  • Segments are horizontal where dxdy​=0dy/dx = 0.
  • If dxdy​dy/dx depends on xx only, segments match down each vertical line; on yy only, along each horizontal line.

  3. 3

  4. 4

Calculus · differential equations

Euler's method

  • A differential equation dxdy​=f(x,y)dy/dx = f(x, y) gives the gradient at every point. Euler's method follows that gradient in small steps of width hh:
yn+1​=yn​+hf(xn​,yn​),xn+1​=xn​+hyₙ₊₁ = yₙ + h f(xₙ, yₙ), xₙ₊₁ = xₙ + h
  • Each step uses the gradient at the start of the step.
  • A smaller step hh usually gives a more accurate estimate (but more steps).
  • In exams the values come from a spreadsheet or your GDC; you must set up the method correctly.

Calculus · differential equations

Coupled systems

  • In a coupled system, two quantities change together and each rate depends on both:
dtdx​=f1​(x,y,t),dtdy​=f2​(x,y,t)dx/dt = f₁(x, y, t), dy/dt = f₂(x, y, t)
  • Predator–prey example: rabbits xx grow on their own but are eaten, foxes yy die out on their own but are fed: dtdx​=ax−bxydx/dt = ax − bxy, dtdy​=−cy+dxydy/dt = −cy + dxy.
  • Euler's method updates both at once, using the old values of xx and yy in both formulas:

xn+1​=xn​+hf1​xₙ₊₁ = xₙ + h f₁, yn+1​=yn​+hf2​yₙ₊₁ = yₙ + h f₂, tn+1​=tn​+htₙ₊₁ = tₙ + h.

Calculus · differential equations

Phase portraits and eigenvalues

  • For dtdx​=ax+bydx/dt = ax + by, dtdy​=cx+dydy/dt = cx + dy, the origin is an equilibrium point. A phase portrait plots yy against xx; each path is a trajectory.
  • The behaviour depends on the eigenvalues of (ac​bd​)( a , b ; c , d ), the roots of λ2−(a+d)λ+(ad−bc)=0λ² − (a + d)λ + (ad − bc) = 0:
EigenvaluesTrajectories
Both negative, or complex with negative real partMove towards the origin (stable)
Both positive, or complex with positive real partMove away from the origin
Real with opposite signsSaddle point
Complex (non-zero real part)Spirals
Purely imaginaryCircles or ellipses round the origin

Question

  1. 1
    Eigenvalues of (12​21​)( 1 , 2 ; 2 , 1 ): λ2−2λ−3=0λ² − 2λ − 3 = 0, so λ=3λ = 3 or λ=−1λ = −1
  2. 2
    Eigenvectors: (11​)( 1 ; 1 ) for λ=3λ = 3 and (1−1​)( 1 ; −1 ) for λ=−1λ = −1
  3. 3
    General solution: (xy​)=Ae3t(11​)+Be−t(1−1​)( x ; y ) = Ae^3t( 1 ; 1 ) + Be^(−t)( 1 ; −1 )
  4. 4
    At t=0t = 0: A+B=3A + B = 3 and A−B=1A − B = 1, so A=2A = 2, B=1B = 1

Calculus · differential equations

Where second-order equations come from

  • Displacement xx, velocity dtdx​dx/dt, acceleration dt2d2x​d²x/dt².
  • A spring pulls back towards equilibrium with force proportional to xx: dt2d2x​=−bxd²x/dt² = −bx with b>0b > 0.
  • Air or friction opposes the motion, with force proportional to the velocity: an extra term −adtdx​−adx/dt, a>0a > 0.
  • Together: dt2d2x​+adtdx​+bx=0d²x/dt² + adx/dt + bx = 0, a second-order differential equation. In exams the equation is given.
Calculus · differential equations

Writing it as a coupled system

  • Let y=dtdx​y = dx/dt (the velocity). Then dt2d2x​=dtdy​d²x/dt² = dy/dt.
  • dt2d2x​+adtdx​+bx=0d²x/dt² + adx/dt + bx = 0 becomes
dtdx​=y,dtdy​=−bx−aydx/dt = y, dy/dt = −bx − ay
  • Its matrix is (0−b​1−a​)( 0 , 1 ; −b , −a ), with eigenvalues from λ2+aλ+b=0λ² + aλ + b = 0.
  • Now the phase portrait rules apply, with xx (displacement) across and yy (velocity) up.
Worked example Calculus · differential equations

Reading the motion from the eigenvalues

Question
Describe the motion given by dt2d2x​+2dtdx​+5x=0d²x/dt² + 2dx/dt + 5x = 0.
  1. 1
    Write as a system: dtdx​=ydx/dt = y, dtdy​=−5x−2ydy/dt = −5x − 2y
  2. 2
    Characteristic equation: λ2+2λ+5=0λ² + 2λ + 5 = 0
  3. 3

  4. 4
    Complex with negative real part: trajectories spiral into the origin
Answer
a damped oscillation. The object swings back and forth with shrinking amplitude and settles at x=0x = 0.
⚠️ Watch out
the phase portrait spirals, but the displacement–time graph is a wave that dies away. Both describe the same motion.

Calculus · differential equations

Euler's method for second-order equations

  • For dt2d2x​=f(x,dtdx​,t)d²x/dt² = f(x, dx/dt, t), set y=dtdx​y = dx/dt and step both equations together:
xn+1​=xn​+hyn​,yn+1​=yn​+hf(xn​,yn​,tn​)xₙ₊₁ = xₙ + h yₙ, yₙ₊₁ = yₙ + h f(xₙ, yₙ, tₙ)
  • Then tn+1​=tn​+htₙ₊₁ = tₙ + h. Both updates use the old values.
  • You need two starting values: the initial displacement and the initial velocity.
  • A spreadsheet or your GDC generates the values in exams.

Mission check

?A spring bounces less each time. Which equation describes its motion?

A damped spring obeys dt2d2x​+adtdx​+bx=0d²x/dt² + adx/dt + bx = 0 with a,b>0a, b > 0: −bx−bx pulls it back and −adtdx​−adx/dt resists the motion. Here λ=−0.3±2.98iλ = −0.3 ± 2.98i, so the phase path spirals into the origin: the spring keeps oscillating, but each bounce is smaller.

Recap

Big ideas

  • Translate words into a differential equation: rate = derivative, "proportional to" = constant times, decreasing = negative.
  • Separate the variables, integrate both sides with one constant, then use the initial condition; dxdy​=kydy/dx = ky gives y=Aekxy = Ae^kx.
  • A slope field shows the gradient at each point; solution curves follow the segments.
  • Euler's method: yn+1​=yn​+hf(xn​,yn​)yₙ₊₁ = yₙ + h f(xₙ, yₙ). For a coupled system, update xx and yy together from the old values; a spreadsheet or GDC does the arithmetic.
  • For dtdx​=ax+bydx/dt = ax + by, dtdy​=cx+dydy/dt = cx + dy, the eigenvalues decide the phase portrait: negative (real part) in, positive out, opposite signs a saddle, complex spirals, imaginary ellipses.
  • With real distinct eigenvalues, (xy​)=Aeλ1​tv1​+Beλ2​tv2​( x ; y ) = Ae^(λ₁ t)v₁ + Be^(λ₂ t)v₂.
  • Write dt2d2x​=f(x,dtdx​,t)d²x/dt² = f(x, dx/dt, t) as dtdx​=ydx/dt = y, dtdy​=f(x,y,t)dy/dt = f(x, y, t), then use Euler's method on both, from the old values.
  • dt2d2x​+adtdx​+bx=0d²x/dt² + adx/dt + bx = 0 has matrix (0−b​1−a​)( 0 , 1 ; −b , −a ) and λ2+aλ+b=0λ² + aλ + b = 0.
  • Imaginary λλ: ellipses (undamped oscillation). Complex with negative real part: spiral in (damped). Real, opposite signs: saddle.
