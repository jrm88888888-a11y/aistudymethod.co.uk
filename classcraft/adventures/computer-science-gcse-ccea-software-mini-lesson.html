Software · types

System software vs application software

All software falls into two big groups depending on who it works for:

  • System software — runs and manages the computer itself. It includes the operating system, utility programs and translators. The user usually doesn't work with it directly.
  • Application software — programs that let the user do a specific task, such as a word processor, web browser, spreadsheet or game.

Quick test: ask "does it help me get a job done (application), or does it run the machine (system)?" A browser lets you do something → application. The operating system runs the computer → system.

System software · operating system

What the operating system does

The operating system (OS) is the most important piece of system software. Three of its core jobs are about allocating resources fairly:

  • Allocating memory — deciding which programs get space in RAM.
  • Allocating storage — managing space on the disk for files.
  • Allocating processing time — scheduling which task the CPU runs next.
  • It also manages hardware/peripherals, provides a user interface, handles file management and security.

System software · processing

Modes of processing

An operating system can handle work in different ways. CCEA names three modes of processing:

  • Real-time processing — data is processed immediately, so the result is up to date (e.g. booking a flight seat).
  • Batch processing — similar jobs are collected together and processed as one lot later, with no user interaction (e.g. printing payslips).
  • Multi-user processing — many users share the same system at the same time (e.g. students on a school network).

System software · utilities

Utility applications

Utility applications are small system-software tools that keep the computer healthy and organised. Key ones for CCEA:

  • Disk defragmenter — reorganises fragmented files so their blocks are next to each other, giving faster access.
  • Backup — makes a spare copy of data; restoring puts that copy back if the original is lost.
  • Task scheduling — sets jobs (like a backup) to run automatically at set times.
  • Antivirus — detects and removes malware. It must be updated regularly because new malware appears constantly, so the virus definitions must stay current.

System software · translators

Translators: compiler, interpreter, assembler

Computers only run machine code (binary). We write programs in high-level languages (like Python) or low-level assembly language, so a translator must convert them. There are three:

  • Compiler — translates the whole high-level program into machine code in one go, producing an executable. It reports all the errors at the end and, once compiled, the program runs fast.
  • Interpreter — translates and runs the program one line/statement at a time. It stops at the first error, so it's easy to debug, but slower to run and needs the interpreter present each time.
  • Assembler — translates assembly language (low-level mnemonics) into machine code, roughly one-to-one.

Don't mix them up: a compiler does the whole lot at once; an interpreter goes line by line and halts on the first error it meets.

The big ideas to know

Two types: system software (runs the computer) vs application software (does a user task)

Operating system: allocates memory · allocates storage · allocates processing time (CPU); also hardware, files, security, interface

Modes of processing: real-time (instant) · batch (collected, run later) · multi-user (shared)

Utilities: defragmenter (reorders fragmented files) · backup/restore · task scheduling · antivirus (update regularly)

Translators: compiler (whole program at once → executable) · interpreter (one line at a time, stops at first error) · assembler (assembly → machine code)
