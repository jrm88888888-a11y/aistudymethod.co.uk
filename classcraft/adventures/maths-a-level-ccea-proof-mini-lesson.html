Proof · deduction, exhaustion, counterexample

What a proof is

  • A proof uses logical steps from assumptions to a conclusion, valid in every case.
  • Examples are not a proof: a statement can hold thousands of times and still fail.
  • P⇒QP ⇒ Q: "PP implies QQ" (if PP then QQ). P⇐QP Leftarrow Q: "PP is implied by QQ". P⇔QP Leftrightarrow Q: each implies the other ("if and only if").
  • If P⇒QP ⇒ Q, then PP is sufficient for QQ and QQ is necessary for PP.
  • ≡≡: identically equal (true for all values). ∴∴: therefore.
  • End with a concluding statement.

Proof · deduction, exhaustion, counterexample

Proof by deduction

  • Deduction: start from a general case and use algebra so the argument covers every case at once.
  • Write integers in general form: any integer nn; consecutive integers nn, n+1n+1, n+2n+2; even 2a2a; odd 2a+12a + 1 (with aa an integer).
  • To show "is a multiple of 3", reach 3×(an integer)3 × (an integer): n+(n+1)+(n+2)=3(n+1)n + (n+1) + (n+2) = 3(n+1).
  • Two odd numbers: (2a+1)+(2b+1)=2(a+b+1)(2a+1) + (2b+1) = 2(a+b+1), which is even. Use different letters aa, bb, or you have only proved it for equal numbers.
Worked example Proof · deduction, exhaustion, counterexample

Showing n3−nn³ − n is a multiple of 6

Question
Prove that n3−nn³ − n is a multiple of 6 for every integer nn.
  1. 1
    Factorise: n3−n=n(n2−1)=(n−1)n(n+1)n³ − n = n(n² − 1) = (n−1)n(n+1)
  2. 2
    Interpret: this is the product of three consecutive integers.
  3. 3
    Among any two consecutive integers one is even, so 2 is a factor.
  4. 4
    Among any three consecutive integers one is a multiple of 3, so 3 is a factor.
  5. 5
    Conclude: 2 and 3 are both factors and share no common factor, so n3−nn³ − n is a multiple of 6 for every integer nn.
Answer
n3−n=(n−1)n(n+1)n³ − n = (n−1)n(n+1) is divisible by both 2 and 3, so it is a multiple of 6.
⚠️ Watch out
testing n=2,3,4n = 2, 3, 4 and getting 6, 24, 60 is not a proof. The factorised form covers every nn.

Proof · deduction, exhaustion, counterexample

Exhaustion and counterexample

  • Proof by exhaustion: split all possibilities into a finite set of cases and prove each one, e.g. nn even or odd, or n=3mn = 3m, 3m+13m+1, 3m+23m+2.
  • Every case must be covered: miss one and the proof fails.
  • Disproof by counterexample: to show "if PP then QQ" is false, find one value where PP is true and QQ is false.
  • One counterexample is enough. No number of examples proves a "for all" statement.
Worked example Proof · deduction, exhaustion, counterexample

Squares and multiples of 3

Question
Prove by exhaustion that the square of any integer is either a multiple of 3 or one more than a multiple of 3.
  1. 1
    Every integer is 3m3m, 3m+13m + 1 or 3m+23m + 2 for some integer mm, so check these three cases.
  2. 2
    Case 1: (3m)2=9m2=3(3m2)(3m)² = 9m² = 3(3m²), a multiple of 3.
  3. 3
    Case 2: (3m+1)2=9m2+6m+1=3(3m2+2m)+1(3m+1)² = 9m² + 6m + 1 = 3(3m² + 2m) + 1
  4. 4
    Case 3: (3m+2)2=9m2+12m+4=3(3m2+4m+1)+1(3m+2)² = 9m² + 12m + 4 = 3(3m² + 4m + 1) + 1
  5. 5
    Conclude: all integers are covered, so n2n² is always 3k3k or 3k+13k + 1.
Answer
In every case n2=3kn² = 3k or n2=3k+1n² = 3k + 1 for an integer kk, so the statement is true.
⚠️ Watch out
Case 3 gives +4+4 at first. Write 4=3+14 = 3 + 1 and move the 3 into the bracket to see the form 3k+13k + 1.

Mission check

?n2+n+41n² + n + 41 is prime for n=0n = 0 to 3939. Is it always prime?

It is not always prime. At n=40n = 40, n2+n=n(n+1)=40×41n² + n = n(n+1) = 40 × 41, so n2+n+41=41×41=1681n² + n + 41 = 41 × 41 = 1681. Forty examples in a row could not prove the claim, and this single counterexample disproves it.

Proof · contradiction (A-level only)

How proof by contradiction works (A2 only)

  • To prove a statement, assume it is false (assume its negation).
  • Reason correctly from that assumption until you reach something impossible: a contradiction.
  • The assumption must have been false, so the original statement is true.
  • Write the negation carefully. "There is no greatest even number" becomes "there is a greatest even number, NN".
  • Finish with "This is a contradiction, so …" and restate the result.

Worked example Proof · contradiction (A-level only)

There is no greatest even number

Question
Prove by contradiction that there is no greatest even number.
  1. 1
    Assume the opposite: there is a greatest even number, NN.
  2. 2
    NN is even, so N=2kN = 2k for some integer kk.
  3. 3
    Then N+2=2k+2=2(k+1)N + 2 = 2k + 2 = 2(k+1), which is even.
  4. 4
    But N+2>NN + 2 > N, so NN is not the greatest even number: a contradiction.
Answer
The assumption is false, so there is no greatest even number.
⚠️ Watch out
showing that 1,000,000 is beaten by 1,000,002 is an example, not a proof. The argument must work for any NN.
Proof · contradiction (A-level only)

Tools for the 2​√2 proof (A2 only)

  • A rational number can be written as ba​a/b with integers aa, bb (b=0b ≠ 0) and no common factor (lowest terms). An irrational number cannot.
  • Key fact: if a2a² is even, then aa is even.
  • Why: if aa were odd, a=2k+1a = 2k + 1, then a2=4k2+4k+1=2(2k2+2k)+1a² = 4k² + 4k + 1 = 2(2k² + 2k) + 1, which is odd.
  • In the 2​√2 proof, the contradiction is that aa and bb turn out to share a factor of 2.
Worked example Proof · contradiction (A-level only)

2​√2 is irrational

Question
Prove by contradiction that 2​√2 is irrational.
  1. 1
    Assume 2​√2 is rational: 2​=ba​√2 = a/b, with aa, bb integers with no common factor.
  2. 2
    Square and rearrange: a2=2b2a² = 2b², so a2a² is even, so aa is even. Write a=2ca = 2c.
  3. 3
    Substitute: 4c2=2b24c² = 2b², so b2=2c2b² = 2c². Then b2b² is even, so bb is even.
  4. 4
    Both aa and bb are even, so they share the factor 2: this contradicts "no common factor".
Answer
The assumption is false, so 2​√2 is irrational.
⚠️ Watch out
the proof needs "no common factor" in step 1. Without it there is nothing to contradict.

Proof · contradiction (A-level only)

Infinitely many primes (A2 only)

  • Assume there are only finitely many primes: p1​,p2​,…,pn​p₁, p₂, …, pₙ.
  • Let N=p1​p2​⋯pn​+1N = p₁ p₂ ⋯ pₙ + 1.
  • Dividing NN by any pi​pᵢ leaves remainder 1, so no prime on the list divides NN.
  • But N>1N > 1, so NN has at least one prime factor (possibly NN itself). That prime is not on the list: a contradiction.
  • So there are infinitely many primes. NN itself need not be prime.
Calculate
?In the proof, suppose the list of primes were 2, 3, 5, 7, 11. Then N=2×3×5×7×11+1N = 2 × 3 × 5 × 7 × 11 + 1. What is the remainder when NN is divided by 7?
Calculate
?A student says: "In this proof, NN is always a new prime." Test it: N=2×3×5×7×11×13+1=30031N = 2 × 3 × 5 × 7 × 11 × 13 + 1 = 30031. Find the smallest prime factor of 30031.
Mission check

?How can you prove there are infinitely many primes without a list?

Suppose there were only finitely many primes. Multiply them all and add 1: the result leaves remainder 1 on division by each of them, so its prime factors are missing from the "complete" list. That contradiction proves there are infinitely many primes, without listing any.

Recap

Big ideas

  • A proof covers every case through logical steps; examples alone never prove a "for all" statement.
  • Deduction uses general algebra (nn, 2a+12a+1, 3m+23m+2); exhaustion splits into a finite set of cases and checks each.
  • One counterexample, where the "if" part holds and the conclusion fails, disproves a statement.
  • Proof by contradiction: assume the negation, reason correctly to something impossible, conclude the original statement is true.
  • 2​√2: assume ba​a/b in lowest terms, show aa and bb are both even.
  • Primes: assume a finite list, consider their product plus 1; it has a prime factor not on the list.
