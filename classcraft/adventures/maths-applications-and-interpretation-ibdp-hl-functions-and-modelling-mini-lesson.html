Gradient and the forms of a line

  • Gradient m=x2​−x1​y2​−y1​​m = (y₂ − y₁)/(x₂ − x₁): the rate of change of yy per unit of xx.
  • Gradient-intercept form: y=mx+cy = mx + c, where cc is the yy-intercept.
  • Point-gradient form: y−y1​=m(x−x1​)y − y₁ = m(x − x₁) through the point (x1​,y1​)(x₁, y₁).
  • General form: ax+by+d=0ax + by + d = 0.
  • A road climbing 1.2 m over 15 m horizontally has gradient 151.2​=0.081.2/15 = 0.08, an 8% incline.

Functions, domain, range and inverses

  • A function gives each input exactly one output. Notation: f(x)f(x), v(t)v(t), C(n)C(n).
  • The domain is the set of allowed inputs; the range is the set of outputs. f(x)=2−x​f(x) = √(2 − x) has domain x≤2x ≤ 2 and range f(x)≥0f(x) ≥ 0.
  • The inverse function f−1f⁻¹ undoes ff: solving f(x)=10f(x) = 10 is the same as finding f−1(10)f⁻¹(10).
  • The graph of f−1f⁻¹ is the reflection of ff in y=xy = x. Only one-to-one functions have inverses; the domain of f−1f⁻¹ is the range of ff.

Functions · composites, inverses and transformations

Composite functions

  • (f∘g)(x)=f(g(x))(f ° g)(x) = f(g(x)): apply gg first, then ff to the result.
  • With f(x)=2x+3f(x) = 2x + 3 and g(x)=x2g(x) = x²: (f∘g)(x)=2x2+3(f ° g)(x) = 2x² + 3 but (g∘f)(x)=(2x+3)2(g ° f)(x) = (2x + 3)². Order matters.
  • In context: n(t)=50tn(t) = 50t phones are made in tt hours and C(n)=200+4nC(n) = 200 + 4n is their cost in £. Then (C∘n)(t)=200+200t(C ° n)(t) = 200 + 200t is the cost after tt hours.
  • g(x)g(x) must lie in the domain of ff for f(g(x))f(g(x)) to exist.

Functions · composites, inverses and transformations

Inverse functions

  • f−1f⁻¹ undoes ff: (f∘f−1)(x)=(f−1∘f)(x)=x(f ° f⁻¹)(x) = (f⁻¹ ° f)(x) = x, the identity function.
  • To undo a chain of steps, undo the last step first, like taking off shoes before socks.
  • Method: write y=f(x)y = f(x), rearrange to make xx the subject, then swap xx and yy.
  • An inverse exists only if ff is one-to-one. If it is not, restrict the domain. The domain of f−1f⁻¹ is the range of ff.

Functions · composites, inverses and transformations

Transformations of graphs

  • Translations: y=f(x)+by = f(x) + b moves the graph up bb; y=f(x−a)y = f(x − a) moves it right aa.
  • Translation by the vector (3−2​)( 3 ; −2 ) (3 right, 2 down): y=f(x−3)−2y = f(x − 3) − 2.
  • Reflections: y=−f(x)y = −f(x) in the xx-axis; y=f(−x)y = f(−x) in the yy-axis.
  • Stretches: y=pf(x)y = pf(x) is vertical, scale factor pp; y=f(qx)y = f(qx) is horizontal, scale factor q1​1/q.
  • Invariant axes: y=pf(x)y = pf(x) fixes the xx-axis; y=f(qx)y = f(qx) fixes the yy-axis.
  • Changes outside ff act on yy-values; changes inside act on xx-values, the opposite way to how they look.

?f(x)=2x+3f(x) = 2x + 3 doubles, then adds 3. Why does f−1f⁻¹ subtract 3 first?

Functions · modelling

Linear and piecewise linear models

  • A linear model f(x)=mx+cf(x) = mx + c fits a quantity that changes by the same amount per unit of xx: mm is the rate, cc the start value.
  • A piecewise model uses different rules on different parts of the domain, like a phone plan with a data allowance, then a charge per GB.
  • Always state a reasonable domain: data used cannot be negative.
  • To make the pieces join up (a continuous model), choose the parameter so both rules agree at the boundary.

Functions · modelling

Exponential growth and decay models

  • An exponential model fits a quantity that changes by the same percentage each step: f(x)=kax+cf(x) = ka^x + c or f(x)=ka−x+cf(x) = ka^(−x) + c (with a>0a > 0), or f(x)=kerx+cf(x) = ke^rx + c.
  • In kaxka^x: a>1a > 1 is growth, 0<a<10 < a < 1 is decay. A 20% fall each year means a=0.8a = 0.8; a 5% rise means a=1.05a = 1.05.
  • The starting value is f(0)=k+cf(0) = k + c.
  • The graph has a horizontal asymptote y=cy = c: decay models get ever closer to cc without reaching it.

Direct and inverse variation

  • Variation models have the form f(x)=axnf(x) = axⁿ, n∈Zn ∈ ℤ.

Functions · modelling

Quadratic models

  • f(x)=ax2+bx+cf(x) = ax² + bx + c, a=0a ≠ 0, fits data that rise then fall (or fall then rise): a thrown ball, an arch, the area of a fenced plot.
  • The vertex gives the maximum (a<0a < 0) or minimum (a>0a > 0); the axis of symmetry is x=−2ab​x = −b/2a.
  • The zeros (use your GDC) often mark where the model starts or ends, such as when a ball lands.
  • Choose a reasonable domain: a height cannot be negative, so the model stops at the zero.

Functions · further modelling

Logistic models

f(x)=1+Ce−kxL​,L,C,k>0f(x) = L/(1 + Ce^(−kx)), L, C, k > 0
  • Use it when growth is restricted: a population on an island, bacteria in a dish, a rumour in a closed group.
  • Early on, growth is close to exponential. As ff nears LL there is less room left, so growth slows.
  • The horizontal asymptote y=Ly = L is the carrying capacity. The starting value is f(0)=1+CL​f(0) = L/(1 + C).
  • Growth is fastest when f=2L​f = L/2, halfway to the limit.

Scaling and linearising with logs

  • Data from 10 to 1,000,000 are hard to plot. Using log10​log₁₀ gives 1 to 6: each step is a factor of 10.
  • If y=abxy = ab^x then lny=lna+xlnbln y = ln a + xln b: a semi-log graph (lnyln y against xx) is a straight line.
  • If y=axby = ax^b then lny=lna+blnxln y = ln a + bln x: a log-log graph (lnyln y against lnxln x) is a straight line.
  • Fit a straight line; read off gradient and intercept, then undo the logs. The plot with rr closer to ±1± 1 points to the better model.

From a semi-log line to a model

Question
For some data, a graph of lnyln y against xx is a straight line, lny=0.4x+1.2ln y = 0.4x + 1.2. Find a model of the form y=abxy = ab^x.
  1. 1
    Compare with lny=lna+xlnbln y = ln a + xln b: lna=1.2ln a = 1.2 and lnb=0.4ln b = 0.4
  2. 2
    Undo the logs: a=e1.2=3.32a = e^1.2 = 3.32, b=e0.4=1.49b = e^0.4 = 1.49 (3 sf)
  3. 3
    Check: ln(3.32×1.49x)=ln3.32+xln1.49≈1.2+0.4xln (3.32 × 1.49^x) = ln 3.32 + xln 1.49 ≈ 1.2 + 0.4x

y=3.32×1.49xy = 3.32 × 1.49^x

the intercept is lnaln a, not aa: writing a=1.2a = 1.2 is the most common slip.

Mission check

?Why do rumours and crazes spread fast, then level off?

A rumour in a group of 1,200 spreads like exponential growth at first, because each new person can tell others. But it can never pass 1,200, so as fewer people are left to hear it, growth slows and the logistic curve N=1+59e−0.8t1200​N = 1200/(1 + 59e^(−0.8t)) levels off at its carrying capacity, 1,200.

  • A line has gradient m=x2​−x1​y2​−y1​​m = (y₂ − y₁)/(x₂ − x₁) and can be written y=mx+cy = mx + c, y−y1​=m(x−x1​)y − y₁ = m(x − x₁) or ax+by+d=0ax + by + d = 0; parallel means m1​=m2​m₁ = m₂, perpendicular means m1​m2​=−1m₁ m₂ = −1.
  • A function has a domain (inputs) and a range (outputs); f−1f⁻¹ undoes ff, exists for one-to-one functions and is the reflection of ff in y=xy = x.
  • Key features (intercepts, zeros, maximum and minimum, asymptotes) and intersections come from a GDC or from solving f(x)=g(x)f(x) = g(x).
  • (f∘g)(x)=f(g(x))(f ° g)(x) = f(g(x)): apply gg first; in general f∘g=g∘ff ° g ≠ g ° f.
  • f−1f⁻¹ undoes ff (last step first); it needs ff to be one-to-one, possibly after restricting the domain, and the domain of f−1f⁻¹ is the range of ff.
  • f(x)+bf(x) + b, −f(x)−f(x), pf(x)pf(x) act on yy-values; f(x−a)f(x − a), f(−x)f(−x), f(qx)f(qx) act on xx-values; the order of transformations matters.
  • Same amount each step: linear f(x)=mx+cf(x) = mx + c (piecewise if the rule changes). Same percentage each step: exponential kax+cka^x + c.
  • An exponential model kax+cka^x + c has horizontal asymptote y=cy = c; decay approaches it but never reaches it.
  • Variation axnaxⁿ: find aa from one point. Choose models from context and data shape; beware extrapolation.
  • For a continuous piecewise model, make the rules agree at each boundary.
  • Quadratic models: vertex for the maximum or minimum, zeros for start and end, and a domain that makes sense.
  • Find a model's parameters by substituting points and solving the linear equations with your GDC.
  • Sinusoidal models: amplitude 2max−min​(max − min)/2, principal axis y=2max+min​y = (max + min)/2, period b360∘​(360°)/b.
  • asin(b(x−c))+dasin (b(x − c)) + d in radians: period b2π​2π/b, phase shift cc.
  • Logistic 1+Ce−kxL​L/(1 + Ce^(−kx)): near-exponential at first, fastest at 2L​L/2, levels off at the carrying capacity LL.
  • Half-life of ke−rtke^(−rt) is rln2​(ln 2)/r; a+blnxa + bln x keeps growing ever more slowly.
