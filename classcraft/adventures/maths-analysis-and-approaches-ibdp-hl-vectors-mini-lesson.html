Vectors · scalar product

Components, magnitude and unit vectors

  • A vector has size and direction: v=​v1​v2​v3​​​=v1​i+v2​j+v3​kv = ( v₁ ; v₂ ; v₃ ) = v₁i + v₂j + v₃k.
  • Position vector OA=aOA→ = a. Displacement AB=b−aAB→ = b − a (end minus start).
  • Magnitude: ∣v∣=v12​+v22​+v32​​|v| = √(v₁² + v₂² + v₃²), so the distance ABAB is ∣AB∣|AB→|.
  • A unit vector has magnitude 1: ∣v∣v​v/(|v|). Vectors are parallel if one is a scalar multiple of the other, w=kvw = kv.

Vectors · scalar product

The scalar product

  • The scalar product (dot product) of vv and ww is a number, not a vector:
v⋅w=v1​w1​+v2​w2​+v3​w3​=∣v∣∣w∣cosθv·w = v₁w₁ + v₂w₂ + v₃w₃ = |v||w|cos θ
  • θθ is the angle between the vectors when they point away from the same point. So cosθ=∣v∣∣w∣v⋅w​cos θ = (v·w)/(|v||w|).
  • For non-zero vectors: v⋅w>0v·w > 0 means θθ is acute, v⋅w=0v·w = 0 means perpendicular, and v⋅w<0v·w < 0 means obtuse.
  • Properties: v⋅w=w⋅vv·w = w·v, u⋅(v+w)=u⋅v+u⋅wu·(v + w) = u·v + u·w, (kv)⋅w=k(v⋅w)(kv)·w = k(v·w) and v⋅v=∣v∣2v·v = |v|². For parallel vectors, ∣v⋅w∣=∣v∣∣w∣|v·w| = |v||w|. You can use these in vector proofs.

The angle between two vectors

Question

  1. 1
    Scalar product: p⋅q=6+0−8=−2p·q = 6 + 0 − 8 = −2
  2. 2
    Magnitudes: ∣p∣=4+1+4​=3|p| = √(4 + 1 + 4) = 3 and ∣q∣=9+0+16​=5|q| = √(9 + 0 + 16) = 5
  3. 3
    Cosine: cosθ=3×5−2​=−152​cos θ = (−2)/(3 × 5) = −2/15
  4. 4
    Inverse cosine: θ=arccos(−152​)θ = arccos (−2/15)
Answer

Worked example Vectors · scalar product

A vector proof: the angle in a semicircle

Question
ABAB is a diameter of a circle with centre OO, and CC is another point on the circle. Let OA=aOA→ = a and OC=cOC→ = c. Prove that AC^B=90∘AĈB = 90°.
  1. 1
    Use the circle: OO is the midpoint of ABAB, so OB=−aOB→ = −a; radii are equal, so ∣c∣=∣a∣|c| = |a|
  2. 2
    Write the sides from CC: CA=a−cCA→ = a − c and CB=−a−cCB→ = −a − c
  3. 3
    Expand the scalar product: CA⋅CB=−(a−c)⋅(a+c)=−(a⋅a+a⋅c−c⋅a−c⋅c)CA→·CB→ = −(a − c)·(a + c) = −(a·a + a·c − c·a − c·c)
  4. 4
    Simplify with a⋅c=c⋅aa·c = c·a and v⋅v=∣v∣2v·v = |v|²: CA⋅CB=−(∣a∣2−∣c∣2)=0CA→·CB→ = −(|a|² − |c|²) = 0
  5. 5
    Conclude: CC is not AA or BB, so both vectors are non-zero, and a zero scalar product means they are perpendicular
Answer
CA⋅CB=0CA→·CB→ = 0, so AC^B=90∘AĈB = 90°, as required.
⚠️ Watch out
justify each fact you use (equal radii, OB=−aOB→ = −a, non-zero vectors). Unexplained steps lose marks in a "prove" question.

Vectors · lines

The vector equation of a line

  • A line through the point with position vector aa, in the direction of bb, is
r=a+λb,λ∈Rr = a + λb, λ ∈ ℝ
  • aa fixes where the line is; the direction vector bb fixes which way it points. Each value of λλ gives one point on the line.
  • Parametric form: write each component separately, x=x0​+λlx = x₀ + λ l, y=y0​+λmy = y₀ + λ m, z=z0​+λnz = z₀ + λ n.
  • Cartesian form: make λλ the subject of each and equate, lx−x0​​=my−y0​​=nz−z0​​(x − x₀)/l = (y − y₀)/m = (z − z₀)/n.

Vectors · lines

Parallel, intersecting or skew

  • Compare the direction vectors first. If one is a multiple of the other, the lines are parallel (or coincident, if they share a point).
  • If not, set the two equations equal: a1​+λb1​=a2​+μb2​a₁ + λb₁ = a₂ + μb₂. Use a different letter for each parameter.
  • Solve two of the component equations for λλ and μμ, then test the third.
  • Third equation true: the lines intersect. False: in 3-D the lines are skew; they are not parallel and never meet.
Worked example Vectors · lines

Finding a point of intersection

Question
Show that the lines r=​1−12​​+λ​21−1​​r = ( 1 ; −1 ; 2 ) + λ( 2 ; 1 ; −1 ) and r=​3−32​​+μ​12−1​​r = ( 3 ; −3 ; 2 ) + μ( 1 ; 2 ; −1 ) intersect, and find the point of intersection.
  1. 1
    Direction vectors are not multiples of each other, so the lines are not parallel
  2. 2
    Equate xx and yy: 1+2λ=3+μ1 + 2λ = 3 + μ and −1+λ=−3+2μ−1 + λ = −3 + 2μ
  3. 3
    Substitute μ=2λ−2μ = 2λ − 2 into the second: −1+λ=−7+4λ−1 + λ = −7 + 4λ, so λ=2λ = 2 and μ=2μ = 2
  4. 4
    Test zz: 2−λ=02 − λ = 0 and 2−μ=02 − μ = 0. Both are 0, so the lines intersect
  5. 5
    Substitute λ=2λ = 2 into the first line: (1+4,−1+2,2−2)(1 + 4, −1 + 2, 2 − 2)
Answer
the lines intersect at (5,1,0)(5, 1, 0).
⚠️ Watch out
you must test the third equation. If the second line started at (3,−3,5)(3, −3, 5), the same λλ and μμ would fail the zz test and the lines would be skew.

Vectors · lines

Lines as motion

  • An object moving with constant velocity vv from position r0​r₀ has position r=r0​+tvr = r₀ + tv at time tt. The parameter is now time.
  • The speed is ∣v∣|v|. The relative position of BB from AA is AB=rB​−rA​AB→ = r_B − r_A.
  • Two paths can cross with no collision. A collision needs the same point at the same time: solve rA​(t)=rB​(t)r_A(t) = r_B(t) with one tt.
Worked example Vectors · lines

Crossing paths

Question
Positions in km relative to a control tower, tt minutes after noon, are rA​=​123​​+t​210​​r_A = ( 1 ; 2 ; 3 ) + t( 2 ; 1 ; 0 ) and rB​=​8−20​​+t​−121​​r_B = ( 8 ; −2 ; 0 ) + t( −1 ; 2 ; 1 ). Do the paths cross, and do the aircraft collide?
  1. 1
    Paths: use different parameters, 1+2s=8−u1 + 2s = 8 − u and 2+s=−2+2u2 + s = −2 + 2u, giving s=2s = 2, u=3u = 3
  2. 2
    Test zz: 3=0+33 = 0 + 3, true. The paths cross at (5,4,3)(5, 4, 3)
  3. 3
    Times: AA is there when t=2t = 2, but BB only when t=3t = 3
  4. 4
    Collision test: xx needs 1+2t=8−t1 + 2t = 8 − t, so t=37​t = 7/3, but zz needs 3=t3 = t. No single tt works
Answer
the paths cross at (5,4,3)(5, 4, 3), but the aircraft do not collide: BB arrives 1 minute after AA has passed.
⚠️ Watch out
using the same letter for both parameters in step 1 would wrongly suggest the paths never meet.

Vectors · planes

The vector product

  • The vector product (cross product) is a vector perpendicular to both vv and ww:
v×w=​v2​w3​−v3​w2​v3​w1​−v1​w3​v1​w2​−v2​w1​​​v×w = ( v₂w₃ − v₃w₂ ; v₃w₁ − v₁w₃ ; v₁w₂ − v₂w₁ )
  • v×w=∣v∣∣w∣sinθnv×w = |v||w|sin θ n, where nn is a unit normal set by the right-hand screw rule.
  • Order matters: w×v=−v×ww×v = −v×w. Also v×v=0v×v = 0, and for non-zero vectors v×w=0v×w = 0 means parallel.
  • ∣v×w∣|v×w| is the area of the parallelogram with sides vv and ww; a triangle is half.

Vectors · planes

Equations of a plane

  • Vector form: r=a+λb+μcr = a + λb + μc, where aa is a point and bb, cc are non-parallel vectors in the plane.
  • A normal nn is perpendicular to every vector in the plane. You can take n=b×cn = b×c.
  • Scalar product form: r⋅n=a⋅nr·n = a·n.
  • Cartesian form: with n=​n1​n2​n3​​​n = ( n₁ ; n₂ ; n₃ ), this is n1​x+n2​y+n3​z=dn₁x + n₂y + n₃z = d, where d=a⋅nd = a·n.

The plane through three points

Question
Find a Cartesian equation of the plane through A(1,0,2)A(1, 0, 2), B(3,1,0)B(3, 1, 0) and C(2,−1,4)C(2, −1, 4).
  1. 1
    Two vectors in the plane: AB=​21−2​​AB→ = ( 2 ; 1 ; −2 ) and AC=​1−12​​AC→ = ( 1 ; −1 ; 2 )
  2. 2
    Normal: AB×AC=​2−2−2−4−2−1​​=​0−6−3​​AB→×AC→ = ( 2 − 2 ; −2 − 4 ; −2 − 1 ) = ( 0 ; −6 ; −3 ), so use n=​021​​n = ( 0 ; 2 ; 1 )
  3. 3
    Find dd using AA: a⋅n=0+0+2=2a·n = 0 + 0 + 2 = 2
  4. 4
    Check with BB and CC: 2(1)+0=22(1) + 0 = 2 and 2(−1)+4=22(−1) + 4 = 2
Answer
2y+z=22y + z = 2
⚠️ Watch out
any non-zero multiple of a normal is also a normal. Dividing by −3−3 keeps the numbers small.

Vectors · planes

Intersections and angles

  • Line and plane: substitute the line's xx, yy, zz (in terms of λλ) into the plane's equation and solve. One λλ: one point. No solution: parallel. True for every λλ: the line lies in the plane.
  • Two planes: non-parallel planes meet in a line, with direction n1​×n2​n₁×n₂. Three planes: solve the system (a point, a line, a plane, or no common point).
  • Angles: between two planes, the acute angle has cosθ=∣n1​∣∣n2​∣∣n1​⋅n2​∣​cos θ = (|n₁·n₂|)/(|n₁||n₂|). Between a line and a plane, sinθ=∣b∣∣n∣∣b⋅n∣​sin θ = (|b·n|)/(|b||n|).
Worked example Vectors · planes

Where a line meets a plane

Question
Find the point where the line r=​120​​+λ​1−12​​r = ( 1 ; 2 ; 0 ) + λ( 1 ; −1 ; 2 ) meets the plane 2x+y−z=32x + y − z = 3.
  1. 1
    Parametric form: x=1+λx = 1 + λ, y=2−λy = 2 − λ, z=2λz = 2λ
  2. 2
    Substitute: 2(1+λ)+(2−λ)−2λ=32(1 + λ) + (2 − λ) − 2λ = 3
  3. 3
    Simplify: 4−λ=34 − λ = 3, so λ=1λ = 1
  4. 4
    Put λ=1λ = 1 into the line: (1+1,2−1,2)(1 + 1, 2 − 1, 2)
Answer
the line meets the plane at (2,1,2)(2, 1, 2). Check: 4+1−2=34 + 1 − 2 = 3.
⚠️ Watch out
substitute the line into the plane, not the plane's normal into the line.

Mission check

?Three points fix a plane. Which direction sticks straight out of it? The plane contains P(1,0,0)P(1, 0, 0), Q(0,2,0)Q(0, 2, 0) and R(0,0,3)R(0, 0, 3).

Take two vectors along edges of the triangle, such as PQ​PQ→ and PRPR→. Their vector product is perpendicular to both, so it is perpendicular to the whole plane: that is the normal, and it gives the plane's equation r⋅n=a⋅nr·n = a·n.

Recap

Big ideas

  • AB=b−aAB→ = b − a, ∣v∣=v12​+v22​+v32​​|v| = √(v₁² + v₂² + v₃²), and a unit vector is ∣v∣v​v/(|v|): normalise, then rescale.
  • v⋅w=v1​w1​+v2​w2​+v3​w3​=∣v∣∣w∣cosθv·w = v₁w₁ + v₂w₂ + v₃w₃ = |v||w|cos θ gives the angle between vectors; zero means perpendicular.
  • A line is r=a+λbr = a + λb: a point plus multiples of a direction; the angle between lines comes from the direction vectors.
  • To compare two lines: parallel if the directions are multiples; otherwise solve with two parameters and test the third equation (intersect or skew).
  • With r=r0​+tvr = r₀ + tv, a collision needs the same point at the same time; crossing paths alone don't collide.
  • v×wv×w is perpendicular to both vectors; ∣v×w∣=∣v∣∣w∣sinθ|v×w| = |v||w|sin θ is the parallelogram's area.
  • A plane is r=a+λb+μcr = a + λb + μc, or r⋅n=a⋅nr·n = a·n, or n1​x+n2​y+n3​z=dn₁x + n₂y + n₃z = d, with normal n=b×cn = b×c.
  • Substitute a line into a plane to intersect them; use normals for angles between planes, and sinθ=∣b∣∣n∣∣b⋅n∣​sin θ = (|b·n|)/(|b||n|) for a line and a plane.
