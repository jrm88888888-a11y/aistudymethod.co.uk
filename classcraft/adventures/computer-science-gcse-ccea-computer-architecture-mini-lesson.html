The CPU · purpose

The CPU — the "brain"

The CPU (Central Processing Unit) is the part of the computer that processes instructions and data and executes programs. It carries out the instructions of a program by fetching them, decoding what they mean, then executing them — over and over, extremely fast.

  • It processes data and runs programs — often described as the "brain" of the computer.
  • It works one instruction at a time, but at billions of steps per second.
  • The instructions and data it works on are held in memory.

Key idea: the CPU does not store programs long-term — that is the job of memory and storage. The CPU's job is to process instructions and data.

The CPU · components

Inside the CPU

CCEA identifies three main parts inside the CPU:

  • Arithmetic Logic Unit (ALU) — carries out all calculations (add, subtract) and logic/comparisons (greater than, equal to, AND/OR).
  • Control Unit (CU) — directs the operations of the CPU: it decodes each instruction and controls the flow of data around the processor.
  • Immediate-access store — very fast memory that holds the data and instructions currently in use.

The CPU · fetch–decode–execute

The fetch–decode–execute cycle

To run a program the CPU repeats a three-step cycle. Special stores called registers help it keep track:

  • Program Counter (PC) — holds the address of the next instruction to be fetched.
  • Memory Address Register (MAR) — holds the address in memory being read from or written to.
  • Memory Data Register (MDR) — holds the data or instruction fetched from (or being written to) memory.
  • Instruction Address Register (IAR) and the ALU also take part as instructions are decoded and executed.

Architecture · Von Neumann

Von Neumann architecture

Most computers use the Von Neumann architecture. Its big idea is the stored-program concept: both the program instructions and the data they work on are stored together in the same memory.

Watch out: because instructions and data share the same memory, the CPU fetches them one at a time along the same path — this is the classic Von Neumann design.

Performance · what makes a CPU faster

What makes a CPU faster?

Three factors affect how quickly a CPU processes instructions:

  • Clock speed — measured in hertz (GHz). A higher clock speed means more cycles per second, so more instructions are processed each second.
  • Cache size — more cache means the CPU can hold more frequently-used data close by, so it makes fewer slow trips to RAM.
  • Number of cores — each core can process instructions, so more cores let the CPU work on several instructions in parallel.
1 GHz = 1 000 000 000 cycles per second1 GHz = 1000 MHz · higher clock speed → more instructions/second

Remember: "GHz" is billions of cycles per second. A 3 GHz CPU does 3 billion clock cycles every second.

Memory · RAM · ROM · cache

Memory: RAM, ROM & cache

Memory is the fast working store the CPU uses while a computer is running. There are three key types:

  • RAM (Random Access Memory) — volatile: holds the programs and data currently in use, and loses its contents when the power is turned off.
  • ROM (Read Only Memory) — non-volatile: keeps its contents without power and holds the start-up / boot instructions.
  • Cache — very small, very fast memory sitting between the CPU and RAM that stores frequently-used data for quick access.

Misconception: RAM is volatile (wiped when power is off), so unsaved work in RAM is lost. ROM keeps its data — it is non-volatile.

Storage · HDD vs SSD

Secondary storage: HDD vs SSD

Secondary storage keeps programs and files permanently, even with the power off. The two main devices are the HDD and the SSD:

  • HDD (Hard Disc Drive) — stores data magnetically on spinning discs with moving parts; usually higher capacity and cheaper per gigabyte, but slower.
  • SSD (Solid State Drive) — uses flash memory with no moving parts; faster, quieter and more robust, but more expensive per gigabyte.

Primary vs secondary: primary memory like RAM is volatile (temporary working store); secondary storage (HDD/SSD) is permanent and keeps data with the power off.

Systems · embedded

Embedded systems

An embedded system is a computer built into a larger device to carry out one specific, dedicated task, rather than being a general-purpose computer.

Key idea: a laptop is a general-purpose computer, but the controller inside a washing machine or microwave is an embedded system — it only ever does its one job.
