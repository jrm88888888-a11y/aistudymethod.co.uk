Describing a transformation fully

  • A full description names the transformation and gives every fact needed to repeat it exactly.
TransformationGiveImage is
Reflectionthe mirror line as an equation, e.g. x=3x = 3 or y=−1y = −1congruent
Rotationcentre, angle, directioncongruent
Translationa column vectorcongruent
Enlargementcentre, scale factorsimilar
  • Reflections, rotations and translations keep lengths and angles. Enlargements keep angles but change lengths.
  • Give one transformation only. Two moves for a "single transformation" question score nothing.
  • Slanted mirror lines such as y=xy = x and y=−xy = −x: Foundation and Higher.
Worked example Geometry · transformations

Describing a rotation

Question
Describe fully the single transformation that maps triangle A, with vertices (1,1)(1, 1), (3,1)(3, 1), (1,2)(1, 2), onto triangle B, with vertices (−1,1)(−1, 1), (−1,3)(−1, 3), (−2,1)(−2, 1).
  1. 1
    Same size and shape, but turned round: it is a rotation.
  2. 2
    Find the angle: side (1,1)(1, 1) to (3,1)(3, 1) points right; its image (−1,1)(−1, 1) to (−1,3)(−1, 3) points up. That is a quarter-turn anticlockwise, 90°.
  3. 3
    Find the centre: try (0,0)(0, 0) with tracing paper. Each vertex and its image are the same distance from it.
  4. 4
    Write all three facts with the word "rotation".
Answer
Rotation, 90° anticlockwise, centre (0,0)(0, 0).
⚠️ Watch out
leaving out the centre, the angle or the direction each loses a mark, and "turn" is not accepted for "rotation".

Geometry · transformations

Translations and enlargements

  • Translation by (ab​)( a ; b ): the top number moves right (+) or left (−); the bottom number moves up (+) or down (−).
  • Enlargement: every distance from the centre is multiplied by the scale factor.
  • A scale factor between 0 and 1 makes the image smaller. Scale factor 21​1/2, centre (0,0)(0, 0): (4,6)→(2,3)(4, 6) → (2, 3).
  • Fractional scale factors: Foundation and Higher.
Worked example Geometry · transformations

Enlargement from a centre

Question
Enlarge triangle T, with vertices (2,3)(2, 3), (3,3)(3, 3), (2,5)(2, 5), by scale factor 2, centre (1,2)(1, 2).
  1. 1
    Count from the centre to each vertex: (11​)( 1 ; 1 ), (21​)( 2 ; 1 ), (13​)( 1 ; 3 )
  2. 2
    Multiply each by 2: (22​)( 2 ; 2 ), (42​)( 4 ; 2 ), (26​)( 2 ; 6 )
  3. 3
    Count out from the centre again: (3,4)(3, 4), (5,4)(5, 4), (3,8)(3, 8)
  4. 4
    Check: the base was 1 and is now 2; the height was 2 and is now 4.
Answer
The image has vertices (3,4)(3, 4), (5,4)(5, 4) and (3,8)(3, 8).
⚠️ Watch out
doubling the coordinates themselves, e.g. (2,3)→(4,6)(2, 3) → (4, 6), is an enlargement about the origin, not about (1,2)(1, 2).

Geometry · transformations

Finding the centre of a rotation

  • The centre is the one point that does not move: an invariant point.
  • Every other point stays the same distance from the centre: CP=CP′CP = CP'.
  • So the centre lies on the perpendicular bisector of PP′PP'. Two such bisectors cross at the centre.
  • On a grid: pin tracing paper at a guess and turn it. If the shape lands on the image, that is the centre.
  • Anticlockwise angles are positive, clockwise negative: −90∘−90° means 90° clockwise.
Calculate
?The point P(5,3)P(5, 3) is rotated 90° clockwise about (2,1)(2, 1). Find the yy-coordinate of its image P′P'.
Mission check

?The nail problem: a picture turns 90° clockwise about a nail. Corner A(5,6)A(5, 6) moves to A′(7,0)A'(7, 0) and corner B(1,6)B(1, 6) moves to B′(7,4)B'(7, 4). Where is the nail?

The nail is the centre of rotation, the one point that does not move. Every other point stays the same distance from it, so the centre is equally far from each point and its image. For this picture only (3,2)(3, 2) passes that test for both corners.

Geometry · vectors

Column vectors

  • A vector has a size and a direction. The column vector (xy​)( x ; y ) means xx across (right is +) and yy up (up is +).
  • Vectors are printed in bold, aa, or written ABAB→ (from A to B). By hand, underline the letter.
  • A translation is described by a column vector: (3−4​)( 3 ; −4 ) moves (1,2)(1, 2) to (4,−2)(4, −2).
  • Equal vectors have the same size and direction, wherever they are drawn.
  • BA=−ABBA→ = −AB→: same size, opposite direction.
Geometry · vectors

Adding, subtracting and scaling (Higher)

  • Add or subtract matching components: (2−1​)+(−34​)=(−13​)( 2 ; −1 ) + ( −3 ; 4 ) = ( −1 ; 3 )
  • On a diagram, a+ba + b means "follow a, then b": draw b starting where a ends. The resultant joins the start to the finish.
  • a−b=a+(−b)a − b = a + (−b): follow a, then b backwards.
  • Multiplying by a scalar (a number) multiplies both components: 3(2−1​)=(6−3​)3( 2 ; −1 ) = ( 6 ; −3 )

Geometry · vectors

Parallel vectors (Higher)

  • kaka is parallel to aa and kk times as long. If k>0k > 0 it points the same way; if k<0k < 0, the opposite way.
  • Test: is one vector a number times the other? (−63​)=−3(2−1​)( −6 ; 3 ) = −3( 2 ; −1 ), so these are parallel (opposite directions).
  • (23​)( 2 ; 3 ) and (32​)( 3 ; 2 ) are not parallel: no single number turns 2 into 3 and 3 into 2.
  • Two journeys line up exactly when the second is a positive multiple of the first.

Geometry · vectors

Vectors in geometry (Higher)

  • Follow a route along known vectors: AB=AO+OB=−a+bAB→ = AO→ + OB→ = −a + b
  • Midpoint M of AB: OM=a+21​(b−a)=21​a+21​bOM→ = a + 1/2(b − a) = 1/2a + 1/2b
  • Show lines are parallel: one vector is a multiple of the other.
  • Show X, Y, Z are collinear: YZ=kXYYZ→ = kXY→ and they share point Y. Example: XY=2a+bXY→ = 2a + b, YZ=6a+3b=3XYYZ→ = 6a + 3b = 3XY→.

Mission check

?A drone flies (34​)( 3 ; 4 ) and then (68​)( 6 ; 8 ). Did it fly in a straight line?

Yes. The second leg is exactly twice the first, (68​)=2(34​)( 6 ; 8 ) = 2( 3 ; 4 ), so it is parallel and points the same way: the drone never turned. Its whole trip is the resultant (912​)=3(34​)( 9 ; 12 ) = 3( 3 ; 4 ).

Recap

Big ideas

  • Describe fully: reflection (mirror line equation), rotation (centre, angle, direction), translation (column vector), enlargement (centre, scale factor).
  • The centre of a rotation is its invariant point: it is equally far from every point and that point's image.
  • Column vector (xy​)( x ; y ): xx right, yy up. Add, subtract and scale component by component.
  • kaka is parallel to aa; a positive kk keeps the direction.
  • Magnitude: ∣a∣=x2+y2​|a| = √(x² + y²).
  • Higher: route along known vectors; collinear means parallel and sharing a point.
