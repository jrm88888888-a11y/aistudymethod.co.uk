System Fundamentals

Systems planning, the role of stakeholders, and system design and analysis.

System Fundamentals is a core part of IB Computer Science. Revise the key concepts and common mistakes below, then lock them in with the free games.

Key concepts

IntegrationCombining separate systems into one solution.
APIDefined interface between software components.
MigrationMoving data or systems to new platforms.
Parallel runningOld and new run together during change.
Direct changeoverSwitch from old to new in one cutover.
BackupCopy of data preserved against loss.
StakeholderPerson or group affected by the system.
End userDirect user of the deployed software.
Functional req.What the system must do.
Non-functional req.Quality attributes (performance, security).
PrototypeEarly model used to elicit feedback.
InterviewDirect technique for gathering needs.
SDLCPhased process: analysis to maintenance.
WaterfallSequential model with distinct stages.

Common mistakes to avoid

Questions where students often pick the tempting wrong answer — make sure you know the right one:

What does a WHILE loop do?✗ Always runs forever.   ✓ Repeats while a condition stays true.
Can a variable's value change while a program runs?✗ No, a variable keeps one value throughout.   ✓ Yes — variables can be reassigned; constants stay fixed.
