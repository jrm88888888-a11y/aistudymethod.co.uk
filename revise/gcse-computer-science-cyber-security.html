GCSE Computer Science Revision

Cyber Security

Cyber threats like malware, phishing and social engineering, and the methods used to protect systems and data.

Cyber Security is a core part of GCSE Computer Science. Revise the key concepts and common mistakes below, then lock them in with the free games.

Key concepts

MalwareMalicious software, including viruses, worms, trojans, ransomware and spyware, designed to damage systems or steal data.
PhishingFraudulent emails or messages that imitate trusted organisations to trick users into revealing passwords, card numbers or other sensitive details.
Brute-force attackAn attack that tries many possible passwords or keys systematically until one works; longer, more complex passwords make it impractical.
Social engineeringManipulating people, rather than technology, into giving away information or access, exploiting trust, fear or urgency.
FirewallSoftware or hardware that monitors traffic entering and leaving a network and blocks traffic that breaks the configured security rules.
EncryptionScrambling data using an algorithm and key so it is unreadable to anyone who intercepts it without the matching key.
ConfidentialityOnly authorised people can see the data.
IntegrityData is accurate and not tampered.
AvailabilityData is accessible when needed by users.
HashingOne-way transform used to check integrity.
BackupA copy of data kept for recovery.
HashA fixed-length fingerprint of some data.
MFAMulti-factor authentication — proof from 2+ sources.
Access levelsRestricting users to only the data they need.

Common mistakes to avoid

Questions where students often pick the tempting wrong answer — make sure you know the right one:

Does a strong password alone keep you safe?✗ Yes, a strong password guarantees safety.   ✓ No — security needs layers (updates, 2FA, caution with phishing).
Is every type of malware a virus?✗ Yes, all malware is a virus.   ✓ No — a virus is one type; others include worms, trojans and ransomware.
What does encryption do?✗ Deletes data permanently.   ✓ Scrambles data so only authorised users can read it.
Are the internet and the World Wide Web the same?✗ Yes, they are the same thing.   ✓ No — the internet is the global network; the web is one service on it.
What does a router do?✗ Stores all the websites you visit.   ✓ Connects different networks and directs data between them.
