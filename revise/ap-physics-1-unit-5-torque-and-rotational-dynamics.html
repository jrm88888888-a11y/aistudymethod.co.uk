Key concepts

Angular position (θ)The angle, measured in radians from a chosen reference line, that locates a point on a rotating rigid system about a specified axis.
Arc length (Δs)The distance a point travels along its circular path about a fixed axis.
Torque (τ)The turning effect of a force exerted on a rigid system about an axis of rotation.
Rotational inertia (I)A measure of a rigid system's resistance to changes in its rotation about a given axis.
Translational equilibriumThe state of a system whose center-of-mass velocity is constant (including zero), which requires the net force exerted on the system to be zero.
Net torque (τ_net, unit: N·m)The sum of the torques exerted on an object or rigid system about one axis, with torques in one sense (clockwise or counterclockwise) positive and the other negative:…
Angular displacement (Δθ)Δθ = θ − θ_0: the angle, in radians, through which a point on a rigid system rotates about a specified axis.
Radian measure in Δs = rΔθΔs = rΔθ is the definition of the radian (an arc equal to the radius subtends 1 rad) rearranged, so the angle must be in radians.
Axis of rotationThe line about which a rigid system rotates or would rotate.
Mass distribution relative to the axisHow far the parts of a system's mass are from the axis of rotation.
Rotational equilibriumThe state of a system whose angular velocity is constant (including zero), which requires the net torque exerted on the system to be zero: Σ τ_i = 0.
Change in angular velocityThe angular velocity of an object or rigid system changes whenever the net torque on it is not zero.
RadianThe angle at the center of a circle that cuts off an arc equal in length to the radius.
Linear (tangential) velocity of a pointA point a distance r from the axis of a rotating rigid system moves along the tangent to its circular path with speed v = rω.

Common mistakes to avoid

Questions where students often pick the tempting wrong answer. Make sure you know the right one:

Can a number of revolutions be used directly as an angular displacement in radians?✗ The number of revolutions a system makes is its angular displacement in radians, so a wheel that turns twice has turned through 2 rad; equally, a quantity in radians can be read as a number of turns.   ✓ No.
Do two systems with the same mass always have the same rotational inertia?✗ Rotational inertia depends only on the mass of a system, so systems of equal mass have equal rotational inertia.   ✓ No.
Does a wheel always turn in the same sense as the net torque exerted on it?✗ An object rotates in the sense of the net torque exerted on it, so when the net torque reverses, the rotation reverses at once.   ✓ No.
